## TL;DR
- Wireshark is a powerful **packet analyzer** (not an IDS). Use the **Display Filter bar** and right-click actions to narrow quickly; use **Export** or **Merge** as needed. :contentReference[oaicite:0]{index=0}
- The core UI has three panes: **Packet List / Details / Bytes**. **Coloring Rules** and conversation-scoped actions help you follow anomalies and flows fast. :contentReference[oaicite:1]{index=1}

## Gotchas
- Wireshark **is not an IDS**; findings rely on analyst skill and filters. :contentReference[oaicite:26]{index=26}
- **Marked Packets are session-local**, whereas **Packet Comments are saved** inside the PCAP. :contentReference[oaicite:27]{index=27}
- For **Find Packet**, pick the correct search **type** (Display filter / Hex / String / Regex) and **pane**. :contentReference[oaicite:28]{index=28}
- After **Follow Stream**, clear the filter with the **X** to return to “all packets.” Use **UTC** time format for incident work. :contentReference[oaicite:29]{index=29}
