## TL;DR

* Wireshark is a packet **analyzer** (not an IDS) that lets you load/merge PCAPs, sniff traffic, dissect protocols, filter/navigate packets, and export data.&#x20;
* Master the display filter bar and right-click actions: **Apply/Prepare as Filter, Conversation Filter, Colourise Conversation, Apply as Column, Follow Stream**.&#x20;

| CMD  | Multi         | User | **Edit → Mark/Unmark Packet**              | Mark packets for later review/export (session-local).                | Marked rows appear in black.                                                         |

| CMD  | Multi         | User | **File → Export Specified Packets…**       | Save a scoped subset for sharing or deeper analysis.                 | Exports only marked/displayed packets.                                               |
| CMD  | Multi         | User | **File → Export Objects → HTTP/SMB/TFTP…** | Recover transferred files from streams.                              | Lists downloadable HTTP objects.                                                     |
| CMD  | Multi         | User | **View → Time Display Format**             | Switch to UTC / preferred timeline for incident work.                | Shows absolute UTC times instead of “since capture start”.                           |
| CMD  | Multi         | User | **Analyse → Apply as Filter**              | One-click filter on a selected field/value.                          | Right-click `ip.src == 10.0.0.5` → filter applied; status shows displayed vs total.  |
| CMD  | Multi         | User | **Analyse → Conversation Filter**          | Show only packets related by IPs/ports (flow-scoped).                | Filters entire TCP conversation.                                                     |
| CMD  | Multi         | User | **View → Colourise Conversation**          | Visually highlight a flow without hiding others.                     | Applies a conversation color; Reset via same menu.                                   |

## Gotchas

* Wireshark **is not an IDS**; findings rely on analyst skill and filters.&#x20;
* **Marked packets** are session-local (lost after closing); **comments** persist in the file.&#x20;
* **Find Packet** works only in the pane you search (list/details/bytes); choose input type (Display filter/Hex/String/Regex).&#x20;
* **Display vs Capture** filters: you used display filters here; capture filters are different and applied at sniff time.&#x20;
* After **Follow Stream** or any filter, click the **X** at the filter bar to clear it and restore all packets.&#x20;
* Use **UTC Time Display Format** to align with SIEM / logs.&#x20;
