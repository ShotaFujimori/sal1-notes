### RAW NOTE
* 6.SAL1 Note_ Linux Shell.pdf
* https://docs.google.com/document/d/1pEmKJmSXR1mPwi5igPnQ9sTEV1rH1_wgwCJQ0RRSSh8/edit?tab=t.0

* **Scope & goals**: Interacting with Linux shells (primarily Bash), using essential commands, comparing **Bash/Fish/Zsh**, and writing basic scripts (variables, loops, conditionals, comments).&#x20;
* **Shell basics**: Typical prompt `user@tryhackme:~$`; default shell is often **Bash**; start in **\$HOME**; use `pwd`, `cd`, `ls`, `cat`; search with `grep`.  &#x20;
* **Identify / switch shells**: `echo $SHELL`; view installed shells via `cat /etc/shells`; temporary switch with `zsh`; permanently set with `chsh -s /usr/bin/zsh`.  &#x20;
* **Scripting essentials**: Create with `nano`, add **shebang** `#!/bin/bash`, make executable `chmod +x`, run with `./script`. Use **variables**, **for-loops**, **if/else**, and **comments** to structure logic.   &#x20;
* **Exercise context**: Practice regex search like `grep -nEi 'cat.*sleep&#124;sleep.*cat' /var/log/authentication.log`; try variants (`-C2`, `-Rli --include='*.log'`). Use `sudo su` when directory access requires elevation. &#x20;

```bash
# Examples from the note

# 1) Find installed shells and switch
cat /etc/shells
zsh        # temporary; tryhackme% prompt
chsh -s /usr/bin/zsh

# 2) First script: variables + shebang
nano first_script.sh
#!/bin/bash
echo "Hey, what’s your name?"
read name
echo "Welcome, $name"
chmod +x first_script.sh
./first_script.sh

# 3) Loop 1..10
cat > loop_script.sh <<'EOF'
#!/bin/bash
for i in {1..10}; do
  echo "$i"
done
EOF
chmod +x loop_script.sh && ./loop_script.sh

# 4) Conditional
cat > conditional_script.sh <<'EOF'
#!/bin/bash
echo "Please enter your name first:"
read name
if [ "$name" = "Stewart" ]; then
  echo "Welcome, Stewart! Here is the secret: THM_Script"
else
  echo "Sorry! You are not authorized to access the secret."
fi
EOF

# 5) Regex search (line-numbered, case-insensitive, ERE)
grep -nEi 'cat.*sleep|sleep.*cat' /var/log/authentication.log
# Handy variants:
grep -nEi -C2 'cat.*sleep|sleep.*cat' /var/log/authentication.log
grep -Rli --include='*.log' 'cat.*sleep|sleep.*cat' /var/log
```
