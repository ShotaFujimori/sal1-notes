
# Gobuster: The Basics — Cheat Sheet
tags: [enum, gobuster, dir, dns, vhost, wordlists, thm]

## TL;DR
Gobuster brute-forces **directories/files**, **DNS subdomains**, and **virtual hosts** using wordlists.  
Core pattern: `gobuster <mode> -u/-d <target> -w <wordlist> [flags]`.

---

## Quick Setup
- Install (Kali/AttackBox already has it): `apt install gobuster`
- Useful wordlists:
  - Directories: `/usr/share/wordlists/dirb/small.txt`, `/usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt`
  - Subdomains: `/usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-5000.txt`

---

## Global Flags You’ll Use a Lot
- `-w <path>`: wordlist  
- `-t 64`: threads (speed vs. stability)  
- `--delay 1500ms`: slow down to evade rate-limits  
- `-o out.txt`: save results  
- `--no-tls-validation`: skip TLS checks (labs/CTFs)  
- `-q`: quiet banner

---

## Mode 1 — Directory & File Enumeration (`dir`)
Find common folders and optional file extensions.

### Minimal
```bash
gobuster dir -u "http://target.tld" -w /usr/share/wordlists/dirb/small.txt
````

### With extensions & redirects

```bash
gobuster dir \
  -u "http://target.tld" \
  -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt \
  -x .php,.js,.txt \
  -r \
  -t 64
```

### Authenticated (when you have creds/cookies)

```bash
gobuster dir -u "https://app.tld" -w /path/to/list.txt \
  -H "Authorization: Bearer <TOKEN>" \
  -c "sessionid=abc123"
```

**Tips**

* Recurse *manually*: if `/admin/` appears, run a second scan with `-u http://target.tld/admin/`.
* Filter noise:

  * Only show certain codes: `-s 200,204,301,302,307,401,403`
  * Hide codes: `-b 404,500`

## Mode 2 — DNS Subdomain Enumeration (`dns`)

Brute-force `*.target.tld` using DNS queries.

### Standard

```bash
gobuster dns \
  -d target.tld \
  -w /usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-5000.txt
```

### Show IPs / use custom resolver

```bash
gobuster dns -d target.tld -w /.../subdomains-top1million-5000.txt \
  -i \
  -r 1.1.1.1
```

**When to use:** you want *DNS-registered* names like `dev.target.tld`, `api.target.tld`.

---

## Mode 3 — Virtual Host Enumeration (`vhost`)

Find **vhosts** (virtual hosts served from the same IP). This sends HTTP requests with different `Host:` headers. Use the **IP** in `-u` and the **base domain** for `--domain`.

### Reliable lab pattern

```bash
gobuster vhost \
  -u "http://10.10.10.10" \
  --domain target.tld \
  -w /usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-5000.txt \
  --append-domain \
  --exclude-length 250-320 \
  -t 64
```

**Why those flags?**

* `-u`: connect to the **IP** (same web server, all vhosts)
* `--domain` + `--append-domain`: build hostnames like `www.target.tld`, `store.target.tld`
* `--exclude-length`: filter false positives (same-length 404 templates)

**Interpreting results**

* Count **200** (OK) responses as *likely real vhosts* (unless a lab or note says otherwise).
* Ignore obvious catch-all/404 patterns and any “secret”/decoy entries called out by the exercise.

---

## Filtering False Positives (fast)

1. Run once **without** `--exclude-length` to observe common 404 body sizes.
2. Re-run with those sizes in `--exclude-length`.
3. Optionally restrict to useful codes: `-s 200,301,302`.

## Practical Recipes

### 1) Quick directory sweep

```bash
gobuster dir -u "http://prod.target.tld" -w /usr/share/wordlists/dirb/small.txt -s 200,301,302 -t 64
```

### 2) Grab a discovered JS flag

```bash
curl http://target.tld/secret/flag.js
# or wget -qO- http://target.tld/secret/flag.js
```

### 3) Find subdomains + resolve IPs

```bash
gobuster dns -d target.tld -w /.../subdomains-top1million-5000.txt -i > subs.txt
```

### 4) Enumerate vhosts behind a single IP

```bash
gobuster vhost -u "http://<SERVER_IP>" --domain target.tld \
  -w /.../subdomains-top1million-5000.txt --append-domain \
  --exclude-length 250-320 -s 200 -t 64
```

---

## Common Gotchas

* **Wrong protocol**: always include `http://` or `https://` in `-u`.
* **Shared hosting**: using the IP in normal browsing may show the wrong site—use `vhost` to vary the `Host` header.
* **No recursion** in `dir`: rescan interesting paths explicitly.
* **TLS errors** on self-signed labs: add `--no-tls-validation`.

## One-Page Reference

* Help: `gobuster --help`, `gobuster <mode> --help`
* Modes: `dir`, `dns`, `vhost` (plus `fuzz`, `s3`, `gcs`, `tftp`)
* Core flags:

  * URL/domain: `-u`, `-d`
  * Wordlist: `-w`
  * Speed: `-t`, `--delay`
  * Filter: `-s`, `-b`, `--exclude-length`
  * Vhost extras: `--domain`, `--append-domain`, `-m GET|POST`, `-r`
  * TLS: `--no-tls-validation`
