# CS101/networking/013_Nmap_The_Basics.md
tags: [nmap, scanning, CS101]

## TL;DR
- **Host discovery**: `-sn` (ping scan), `-sL` (list only), force scan with `-Pn`.
- **Port scans**: TCP **connect** `-sT`, TCP **SYN** (stealth) `-sS`, **UDP** `-sU`; choose ports with `-p` / `-F` / `-p-`.
- **Fingerprinting**: versions `-sV`, OS `-O`, everything `-A` (OS+versions+traceroute).
- **Speed**: timing `-T0..5`, rates `--min-rate/--max-rate`, probes `--min-parallelism/--max-parallelism`, timeout `--host-timeout`.
- **Output/verbosity**: `-v/-vv...`, `-d/-d9`, save with `-oN/-oX/-oG/-oA`.

## Quick-Ref: Nmap Basics

### host-discovery
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | N/A | Ping scan `-sn` | Find live hosts without port scanning | `nmap -sn 192.168.1.0/24` → `N hosts up` |
| TERM | Any | N/A | List scan `-sL` | Show targets (no packets sent) | `nmap -sL 192.168.0.1/27` → lists .1–.31 |
| TERM | Any | N/A | Treat hosts as up `-Pn` | Skip host discovery (firewalls drop ping) | `nmap -Pn target` |
| CMD  | Any | root recommended | TCP SYN/ACK/UDP pings `-PS/-PA/-PU` | Fine-tune how “up” is detected | `nmap -sn -PS80,443 example.com` |

### port-scanning (TCP/UDP)
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | User | **Connect scan** `-sT` | Full TCP 3-WHS; works without raw sockets | `nmap -sT 10.0.0.5` |
| TERM | Any | **root** | **SYN scan** `-sS` | Stealthier, faster; requires raw packets | `nmap -sS 10.0.0.5` |
| TERM | Any | **root** | **UDP scan** `-sU` | Discover UDP services (DNS/NTP/SNMP/… ) | `nmap -sU 10.0.0.5` |
| CMD  | Any | User | Port range `-p` | Focus or go exhaustive | `-p80,443` / `-p1-1024` / `-p-` |
| CMD  | Any | User | Fast mode `-F` | Scan top 100 TCP ports | `nmap -F 10.0.0.5` |
| CMD  | Any | User | Show open only `--open` | Easier counting/reporting | `nmap -sT -p- --open 10.0.0.5` |

### fingerprinting (versions / OS)
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | User | Version detect `-sV` | Identify service & version | `nmap -sV 10.0.0.5` → `lighttpd 1.4.x` |
| TERM | Any | **root** | OS detect `-O` | Guess kernel/OS family | `nmap -O 10.0.0.5` |
| CMD  | Any | **root** | Aggressive `-A` | `-O + -sV + traceroute` | `nmap -A 10.0.0.5` |

### timing & performance
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | User | Timing `-T0..5` | 0=paranoid … 5=insane; default `-T3` | `-T4` = **aggressive** |
| CMD  | Any | User | Min/max rate | Packet rate caps | `--min-rate 500 --max-rate 5000` |
| CMD  | Any | User | Parallelism | Probe concurrency | `--min-parallelism 10` |
| CMD  | Any | User | Host timeout | Bail on slow hosts | `--host-timeout 2m` |

### output & verbosity
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| CMD  | Any | User | Verbose `-v/-vv...` | Live progress & extra detail | `nmap -v target/24` |
| CMD  | Any | User | Debug `-d/-d9` | Deep troubleshooting | `nmap -d4 target` |
| CMD  | Any | User | Save all `-oA` | Write normal/XML/grepable | `nmap -oA scan_out 10.0.0.5` |
| CMD  | Any | User | Specific formats | Choose one format | `-oN out.nmap` / `-oX out.xml` / `-oG out.gnmap` |

## Gotchas
- **Privileges matter**: without root, Nmap falls back to `-sT` (no raw SYN); with root, you get `-sS`.
- **Noise vs stealth**: `-sS` + lower `-T` is quieter; `-A` and `-T4/T5` are noisy and trigger logs/IDS.
- **Local vs remote**: on local L2, host discovery uses **ARP**; remote subnets rely on ICMP/TCP/UDP probes.
- **UDP reality**: many UDP ports look “open|filtered”; use app-aware scripts or `-sU -sV` where possible.
- **Legal/ETI**: scan only what you’re authorized to scan.
