tags: [tcpdump, pcap, CS101]

## TL;DR
- `tcpdump` captures packets from an interface or a pcap file; save with `-w`, read with `-r`.
- Use `-n/ -nn` to avoid slow name/port resolution, `-c` to limit count, `-v/-vv/-vvv` for verbosity.
- Filter by **host/port/protocol**, combine with `and / or / not`.
- For TCP flags, use header-byte filters like `tcp[tcpflags] == tcp-rst`.

## Quick-Ref: Tcpdump Basics

### capture-basics
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| CMD | Linux/macOS | root/sudo | `tcpdump -i any` | Live-capture on all interfaces | `listening on any …` |
| CMD | Multi | root/sudo | `tcpdump -i eth0 -c 50` | Limit packet count | `50 packets captured` |
| CMD | Multi | root/sudo | `tcpdump -i wlo1 -w out.pcap` | Save capture to pcap | (no stdout; file written) |
| CMD | Multi | User | `tcpdump -r out.pcap` | Read/display from pcap | `reading from file out.pcap …` |
| CMD | Multi | User | `tcpdump -r out.pcap -n` | Numeric addrs only | `IP 192.0.2.10.12345 > 198.51.100.20.80` |
| CMD | Multi | User | `tcpdump -r out.pcap -nn` | Numeric addrs & ports | `… > 198.51.100.20.443` |
| CMD | Multi | User | `tcpdump -r out.pcap -v` | Verbose (TTL, id, len) | `… ttl 63 id 0 …` |

### filters-host-port-proto
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| CMD | Multi | User | `host` | Any dir. host filter | `tcpdump host example.com` |
| CMD | Multi | User | `src host` / `dst host` | Source/destination host | `tcpdump src host 192.0.2.5` |
| CMD | Multi | User | `port <num>` | Any dir. port filter | `tcpdump port 53` |
| CMD | Multi | User | `src port` / `dst port` | Source/destination port | `tcpdump dst port 443` |
| CMD | Multi | User | `ip` / `ip6` / `tcp` / `udp` / `icmp` | Protocol filters | `tcpdump icmp` |
| CMD | Multi | User | `and / or / not` | Boolean composition | `tcpdump udp or icmp` |

### display-format
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| CMD | Multi | User | `-q` | Quick/brief output | `IP A.B.C.D:443 > E.F.G.H: tcp 25` |
| CMD | Multi | User | `-e` | Show L2 header (MAC) | `44:df:65:… > 02:83:1e:…` |
| CMD | Multi | User | `-A` | Print ASCII payload | `GET /index.html …` |
| CMD | Multi | User | `-xx` | Hex dump | `0x0000: 4500 004d …` |
| CMD | Multi | User | `-X` | Hex + ASCII | Hex and ASCII side by side |

### counting-and-export
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| CMD | Multi | User | `| wc -l` | Count printed packets | `tcpdump -r file.pcap icmp | wc -l` |
| CMD | Multi | User | `-w <file>` with filter | Save only filtered pkts | `tcpdump -r in.pcap 'icmp' -w icmp_only.pcap` |

### tcp-flags (advanced)
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | N/A | `tcp[tcpflags]` | TCP flags header byte | Use in comparisons |
| CMD | Multi | User | `tcpdump 'tcp[tcpflags] == tcp-syn'` | Only SYN set (no ACK/FIN/…) | SYN-only segments |
| CMD | Multi | User | `tcpdump 'tcp[tcpflags] & tcp-syn != 0'` | At least SYN set | SYN or SYN/ACK |
| CMD | Multi | User | `tcpdump 'tcp[tcpflags] == tcp-rst'` | **Only RST set** | RST-only segments |
| CMD | Multi | User | `tcpdump 'tcp[tcpflags] & (tcp-syn|tcp-ack) != 0'` | SYN or ACK present | handshake/ack flows |

> **Exercise helper**  
> “How many packets have only the TCP Reset (RST) flag set?”  
> From a pcap:  
> `tcpdump -nnr capture.pcap 'tcp[tcpflags] == tcp-rst' | wc -l`

## Gotchas
- Live capture usually needs root/sudo; reading a pcap does **not**.
- `-n` avoids DNS lookups; use `-nn` to also avoid service-name (port) lookups.
- Filters run in kernel via BPF—typos return 0 packets without error; test with a small `-c`.
- When exporting with `-w`, no packets are printed; verify with `ls -lh` or read back with `-r`.
