## TL;DR
- Wireshark is a powerful **packet analyzer** (not an IDS). Use the **Display Filter bar** and right-click actions to narrow quickly; use **Export** or **Merge** as needed.
- The core UI has three panes: **Packet List / Details / Bytes**. **Coloring Rules** and conversation-scoped actions help you follow anomalies and flows fast.

## Quick-Ref: Wireshark Basics

### gui-basics

| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | N/A | Toolbar | Central place to start/stop capture, filter, export, and merge | Use File / View / Analyze menus. |
| TERM | Any | N/A | Display Filter Bar | The most important input for display filters | Typing `http` shows only HTTP packets. |
| CMD | Multi | User | File → Open | Load a PCAP for analysis | Header shows filename and packet count. |
| CMD | Multi | User | File → Merge… | Combine two PCAPs, then save | Confirm the total packet count before merging. |
| CMD | Multi | User | Statistics → Capture File Properties | Inspect file metadata | Hashes, interface, comments, etc. |
| CMD | Multi | User | View → Time Display Format | Switch from relative time to UTC or preferred format | Easier timeline alignment during incidents. |

### packet-dissection (layers)

| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | N/A | Frame (L1) | Frame-level attributes | Length, arrival time, interface id. |
| TERM | Any | N/A | Ethernet (L2) | MAC-layer fields | Src/Dst MAC addresses. |
| TERM | Any | N/A | IP (L3) | IP-layer fields | Src/Dst IP, TTL, DF bit. |
| TERM | Any | N/A | TCP/UDP (L4) | Transport details | Ports, flags, seq/ack, reassembly notes. |
| TERM | Any | N/A | Application (L5) | Decoded app-layer protocols | Example: `GET /index.html` with payload preview. |

### packet-navigation

| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | N/A | Packet Numbers | Every packet is numbered | Stable references in large PCAPs. |
| CMD | Multi | User | Go → Go to Packet | Jump to a specific number or next-in-conversation | Navigate straight to a time of interest. |
| CMD | Multi | User | Edit → Find Packet | Search via Display filter, Hex, String, or Regex in a chosen pane | Choose the correct pane before searching. |
| CMD | Multi | User | Edit → Mark Packet | Mark packets for later review/export | Marks are session-local (cleared on close). |
| CMD | Multi | User | Packet Comments | Persist comments inside the PCAP | Useful for collaborative analysis notes. |

### filtering-and-conversation

| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| CMD | Multi | User | Analyze → Apply as Filter | Instantly apply a filter for the selected field/value | Auto-builds `ip.src == 10.0.0.5`, etc. |
| CMD | Multi | User | Analyze → Prepare as Filter | Compose filters in the bar before applying | Build AND/OR logic safely, then run. |
| CMD | Multi | User | Analyze → Conversation Filter | Show only packets in the selected conversation | Great for following a flow end-to-end. |
| CMD | Multi | User | View → Colourise Conversation | Color a conversation without hiding others | Reset via the same menu. |
| CMD | Multi | User | Analyze → Apply as Column | Add any dissected field as a sortable column | Example: add `tcp.stream` as a column. |
| CMD | Multi | User | Analyze → Follow TCP or UDP Stream | Reconstruct application data from a flow | Auto-applies a stream filter while viewing. |

### export-and-objects

| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| CMD | Multi | User | File → Export Specified Packets | Save a subset PCAP for sharing or deeper work | Export displayed or marked packets only. |
| CMD | Multi | User | File → Export Objects → HTTP etc. | Extract transferred files from streams | Recover and save HTTP/SMB/TFTP objects. |

## Gotchas
- Wireshark **is not an IDS**; findings rely on analyst skill and filters.
- **Marked Packets are session-local**, whereas **Packet Comments are saved** inside the PCAP.
- For **Find Packet**, pick the correct search **type** (Display filter / Hex / String / Regex) and **pane**.
- After **Follow Stream**, clear the filter with the **X** to return to “all packets.” Prefer **UTC** time for incident timelines.
