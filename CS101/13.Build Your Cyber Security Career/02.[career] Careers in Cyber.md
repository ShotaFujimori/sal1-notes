
# SAL1 Cheat-Sheet — Build Your Cyber Security Career: Careers in Cyber

## TL;DR

* Cyber careers are in high demand (millions of unfilled roles), pay well, and span offensive, defensive, and analytical tracks. 
* Map yourself to a role by aligning **responsibilities**, **starter learning paths**, and **tool exposure**. Use this as a quick role chooser + first-90-days guide.

---

## Role Matrix (Responsibilities • First Steps • Typical Tools)

### 1) Security Analyst (Blue Team)

**Core**: Maintain org security posture; analyze networks; report and recommend controls. 
**Day-1 wins**

* Set up log visibility (SIEM dashboards), define alert hygiene, start weekly risk notes.
* Draft “Top 5 Detections to Tune” list.
  **Starter paths**: Pre-Security → Cyber Security 101 → SOC Level 1. 
  **Go-to tools**: SIEM (Splunk/ELK), EDR, vuln scanner, ticketing.

### 2) Security Engineer

**Core**: Design/implement controls; test & harden systems; monitor and remediate. 
**Day-1 wins**

* Baseline hardening (CIS), roll out logging/metrics SLOs, patch SLAs.
* Automate a control (e.g., IaC guardrail).
  **Starter paths**: SOC L1 → Jr. Pentester → Offensive Pentesting. 
  **Go-to tools**: IaC (Terraform/Ansible), WAF, SAST/DAST, secret scanning.

### 3) Incident Responder

**Core**: Detect, triage, contain, and recover during active attacks; optimize MTTD/MTTA/MTTR. 
**Day-1 wins**

* Validate IR runbooks; run a tabletop; define severity matrix and comms tree.
* Build containment playbooks (EDR isolate, identity lockout).
  **Starter path**: SOC Level 1. 
  **Metrics**: MTTD, MTTA, MTTR. 

### 4) Digital Forensics Examiner

**Core**: Acquire, preserve, and analyze digital evidence; document findings. 
**Day-1 wins**

* Create chain-of-custody forms; build triage checklist (memory, disks, cloud).
* Stand up a minimal forensics lab VM.
  **Go-to tools**: Autopsy, Volatility, KAPE, FTK/EnCase.

### 5) Malware Analyst (Reverse Engineer)

**Core**: Static/dynamic analysis; produce IOCs and behavior reports; strong low-level skills. 
**Day-1 wins**

* Set up safe sandbox (REMnux/FlareVM); document detonation SOP.
* Start a signature/IOC repo (YARA/Sigma).
  **Go-to tools**: Ghidra/IDA, x64dbg, ProcMon, Cuckoo. 

### 6) Penetration Tester (Ethical Hacker)

**Core**: Simulate attacks, exploit vulns, and deliver risk-prioritized reports. 
**Day-1 wins**

* Define rules of engagement; pick a reporting template; plan recon → exploit → post-ex.
* Quick wins: attack surface inventory + top misconfig checks.
  **Starter paths**: Jr. Pentester → Offensive Pentesting. 
  **Go-to tools**: Nmap, Burp, Metasploit, LinPEAS/WinPEAS.

### 7) Red Teamer

**Core**: Emulate threat actors to test detection/response; maintain persistence; avoid detection. 
**Day-1 wins**

* Align to an intel-driven scenario (e.g., MITRE ATT&CK TTP set).
* Pre-agree deconfliction + safety signals; define detection objectives.
  **Starter paths**: Jr. Pentester → Offensive Pentesting → Red Teamer.

## Why Cyber? (Fast Facts)

* **High pay, high demand, exciting work** across many sub-disciplines.

## 90-Day Plan Template (Any Role)

1. **Observe**: Baseline your environment (logs, assets, controls).
2. **Measure**: Pick 3–5 KPIs (e.g., vuln SLA, alert fidelity, MTTD).
3. **Improve**: Ship two quick automations or detections.
4. **Report**: Monthly 1-pager to stakeholders (findings → actions → impact).

---

## Career Navigation & Learning

* Use role-specific **learning paths** listed above to build fundamentals + hands-on. 
* Pair technical training with **report writing, metrics, and stakeholder comms**.

---

## Gotchas (Common Pitfalls)

* **Tool > Outcome trap**: Collect tools, forget measurable risk reduction. Tie every task to a metric.
* **No scoping** (Offense): Incomplete ROE causes rework or risk; always lock scope & comms.
* **Alert fatigue** (Defense): Start by **reducing noise**; tune before adding rules.
* **IR chaos**: Without a comms plan, response time balloons; pre-assign roles.
* **RE safety**: Analyze malware in isolated, instrumented environments only.
* **Reporting gap**: Great technical work that doesn’t land with leadership won’t drive change—use executive summaries & clear next steps.

## “Which Role Fits Me?” Quick Heuristics

* Love puzzles + low-level code? → **Malware Analyst**. 
* Like investigations & writing? → **Analyst** / **DFIR**. 
* Enjoy breaking things systematically? → **Pentester / Red Team**. 
* Prefer building guardrails at scale? → **Security Engineer**.
