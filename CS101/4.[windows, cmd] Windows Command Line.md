# SAL1/windows\_command\_line.md

tags: \[windows, cmd]

## TL;DR

* Core `cmd.exe` skills: quickly check environment with **systeminfo / ver / set / help**; page long output with `more`.
* Network triage staples: **ipconfig (/all), ping, tracert, nslookup, netstat (-abon)**.
* File ops you’ll use constantly: **dir (/a /s), cd, tree, copy, move, del/erase, mkdir, rmdir, type**.
* Process control: **tasklist (/FI …)** to filter, **taskkill /PID …** to terminate.
* Power control: **shutdown /r** to reboot, **shutdown /a** to cancel a scheduled shutdown.

## Gotchas

* **`netstat -b` requires Administrator** to show owning process names (hence `Admin` in the Priv column for `-abon`).
* Killing other users’/protected processes with `taskkill` generally requires elevation.
* `del` is irreversible—double-check the target path.
* Some hops in `tracert` may show `*` due to firewall/ICMP policy.
* Page long output with `| more`; interrupt with **Ctrl+C**.
