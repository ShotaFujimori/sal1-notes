# CS101/08_Networking_Core_Protocols.md

tags: [CS101, Networking, Core]

## TL;DR
- TCP uses the **3-way handshake (SYN → SYN/ACK → ACK)**; teardown is **FIN** (graceful) or **RST** (immediate).
- **MSS ≈ MTU − (IP + TCP)**. IPv4 with MTU 1500 → MSS **1460**, IPv6 → **1440**.
- **PMTUD** (Path MTU Discovery). IPv6 does **no in-path fragmentation**; **ICMPv6 Type 2** is essential.
- Start by measuring with **ss / Get-NetTCPConnection / ping(DF)** and **Wireshark filters**.

## Gotchas
- **IPv6 does not fragment at routers** → blocking **ICMPv6** breaks only “large” flows (**PMTUD failure**).
- **RST vs FIN**: RST = abnormal/instant close, FIN = graceful/half-close per side.
- To spot SYN floods or stalls, use `ss -tin state syn-recv` (Linux) to watch half-opens.
- DNS: split-horizon results differ by resolver; local cache/systemd-resolved may mask changes.
- WHOIS/RDAP: rate-limits & GDPR redactions—prefer RDAP for structured data.
- HTTPS: forget -servername (SNI) → wrong cert on shared hosts. Clock skew breaks validation.
- FTP: plain FTP is clear-text; use FTPS or SFTP. Passive mode for NAT/firewalls.
- Mail: many servers require AUTH + TLS; blocklist/greylist can make port-25 tests misleading.
