## TL;DR

* Core Linux network management has moved from **net‑tools** (ifconfig, netstat, route) to **iproute2** (ip, ss, tc, etc.). Learn the new commands first.
* Master a handful of Google operators (`"exact phrase"`, `filetype:`, `site:`, `-`) to laser‑focus OSINT searches.
* Bookmark essential infosec web services—**Shodan, Censys, VirusTotal, Have I Been Pwned, NVD, Exploit DB**—for device discovery, malware triage, breach checks and vuln research.
* Use **ss -tulnp** (Linux) or **netstat -anob** (Windows, run as admin) to quickly find which process is bound to which port.

## Gotchas

* **ss vs. netstat** – On modern Linux, `ss` is faster and shows more protocol info; `netstat` is deprecated.
* `netstat -anob` requires an elevated (Administrator) shell on Windows—otherwise you’ll see “Access is denied.”
* Don’t forget the colon in `filetype:` and `site:` operators—`filetype` without colon is ignored by Google.
* Traffic shaping (`tc`) changes are not persistent; use network scripts or `systemd-networkd` for boot‑time config.
* Shodan and Censys free tiers rate‑limit queries—cache results when possible.
