## TL;DR
- Use `-i` to pick an interface, `-w` to save to PCAP, `-r` to read a PCAP, `-c` to limit count, and `-n/-nn` to skip name/port resolution. :contentReference[oaicite:0]{index=0}
- Filter by **host/port/protocol** for basics; for advanced work, use **pcap-filter** syntax (e.g., `tcp[tcpflags]`) and binary logic. :contentReference[oaicite:1]{index=1}

## Quick-Ref: Tcpdump basics

### tcpdump
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | N/A | tcpdump | CLI packet capture/reader built on libpcap; fast & stable | Save, read, and filter PCAPs efficiently. :contentReference[oaicite:2]{index=2} |
| CMD | Linux/macOS | root | `tcpdump -i eth0 -c 50 -v` | Capture 50 packets on `eth0`, verbose | `listening on eth0 … 50 packets captured` :contentReference[oaicite:3]{index=3} |
| CMD | Linux/macOS | root | `tcpdump -i wlo1 -w data.pcap` | Live-capture to file (no stdout scrolling) | file `data.pcap` written; stop with Ctrl-C. :contentReference[oaicite:4]{index=4} |
| CMD | Multi | User | `tcpdump -r traffic.pcap -n -c 5` | Read first 5 packets from a PCAP (no DNS lookups) | `reading from file traffic.pcap …` + 5 lines. :contentReference[oaicite:5]{index=5} |
| CMD | Multi | User | `tcpdump -i any -nn` | Show live on all IFs; no DNS **and** no service name resolution | e.g., `IP 192.0.2.5.443 > 198.51.100.2.52344: …` :contentReference[oaicite:6]{index=6} |
| CMD | Multi | User | `tcpdump -v / -vv / -vvv` | Increase verbosity (TTL, ID, options, etc.) | Prints more header fields. :contentReference[oaicite:7]{index=7} |
| CMD | Multi | User | `tcpdump host example.com -w http.pcap` | Filter by host (both directions) and save | `… 13 packets captured` (example) :contentReference[oaicite:8]{index=8} |
| CMD | Multi | User | `tcpdump port 53 -n` | Filter by port (DNS uses 53 TCP/UDP) | Shows DNS queries/answers. :contentReference[oaicite:9]{index=9} |
| CMD | Multi | User | `tcpdump icmp -n` | Filter by protocol | Shows echo req/reply, time-exceeded, etc. :contentReference[oaicite:10]{index=10} |

### advanced filtering (tcp flags)
| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |
|---|---|---|---|---|---|
| TERM | Any | N/A | `tcp[tcpflags]` | Address the TCP flags byte for bitwise tests | Enables precise SYN/ACK/FIN/RST filters. :contentReference[oaicite:11]{index=11} |
| CMD | Multi | User | `tcpdump -r cap.pcap 'tcp[tcpflags] == tcp-syn'` | **Only** SYN set | Prints SYNs (others clear). :contentReference[oaicite:12]{index=12} |
| CMD | Multi | User | `tcpdump -r cap.pcap 'tcp[tcpflags] & tcp-syn != 0'` | At least SYN set (SYN or SYN+ACK) | All packets with SYN bit. :contentReference[oaicite:13]{index=13} |
| CMD | Multi | User | `tcpdump -r cap.pcap 'tcp[tcpflags] & (tcp-syn|tcp-ack) != 0'` | SYN **or** ACK set | Broad handshake filtering. :contentReference[oaicite:14]{index=14} |
| CMD | Multi | User | `tcpdump -r cap.pcap 'tcp[tcpflags] == tcp-rst'` | **Only** RST set | RST-only packets (no ACK/FIN/etc.). :contentReference[oaicite:15]{index=15} |
| CMD | Multi | User | `tcpdump -r cap.pcap 'tcp[13] = 0x04'` | Same as above w/o named constant | Offset 13 is flags; `0x04` = RST. :contentReference[oaicite:16]{index=16} |

| Type | OS / Platform | Priv | Command / Term | What it is / Why you care | Example invocation → trimmed output |

## Gotchas
- Live capture often needs **root/admin**; reading a file with `-r` does **not**. :contentReference[oaicite:22]{index=22}  
- `-w` writes to a file and suppresses live printing—this is **expected**. :contentReference[oaicite:23]{index=23}  
- `-n` skips DNS lookups; `-nn` also skips service-name resolution (e.g., `443` stays `443`). :contentReference[oaicite:24]{index=24}  
- Prefer capturing **broadly** and narrowing with display tools later; missed packets can’t be recovered. :contentReference[oaicite:25]{index=25}
