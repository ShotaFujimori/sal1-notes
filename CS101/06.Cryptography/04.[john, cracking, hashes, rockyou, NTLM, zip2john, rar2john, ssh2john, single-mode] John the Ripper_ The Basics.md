## TL;DR
- John the Ripper (“Jumbo” build) cracks many hash formats quickly and supports helper tools (zip2john/rar2john/ssh2john/unshadow). :contentReference[oaicite:0]{index=0}
- Typical workflow: (1) get a hash (or convert target to a hash) → (2) identify/select format → (3) run `john` with a wordlist → (4) show results.
- For Linux `/etc/shadow` you must **unshadow** with `/etc/passwd`; for Windows, NTLM hashes come from SAM/NTDS and can also be “pass-the-hash”.
- Single Crack Mode guesses passwords by **mangling** usernames/GECOS data; **custom rules** let you codify common human patterns (e.g., `Word1!`).

## Gotchas
- Auto format detection can misidentify—**force `--format`** (e.g., `raw-md5`, `raw-sha256`, `nt`) for reliability.
- **Single mode** requires `username:hash` input; without the username John can’t mangle effectively.
- For `/etc/shadow`, always **unshadow** first; feeding `shadow` alone will fail.
- Some package builds lack helpers; use **Jumbo** or install helper scripts (zip2john/rar2john/ssh2john).
- Strong KDFs (e.g., `sha512crypt` with rounds, bcrypt, PBKDF2) slow cracking—but weak passwords still fall to wordlists.

## Important terms & concepts
- **Jumbo John**: Community “jumbo” build with many formats and helper tools.
- **Wordlist attack**: Try candidate passwords from a file (e.g., **rockyou.txt**) hashed and compared.
- **Format / `raw-` prefix**: John’s internal name for hash type; many straight hex digests use `raw-*` (e.g., `raw-md5`).
- **Potfile**: John’s local store of recovered passwords; viewed with `john --show`.
- **NTLM / NTHash**: Windows password hash scheme; stored in **SAM** / **NTDS.dit**; sometimes used in **pass-the-hash**.
- **LM**: Legacy Windows hash (weak); John may mention it when heuristically guessing formats.
- **unshadow**: Tool that merges `/etc/passwd` and `/etc/shadow` into John-readable lines.
- **Single Crack Mode**: Username/GECOS-driven mangling to generate likely passwords.
- **GECOS**: User info fields in `/etc/passwd`; John can leverage names/dirs in single mode.
- **zip2john / rar2john / ssh2john**: Converters that extract a crackable hash from ZIP, RAR, and OpenSSH private keys.
- **sha512crypt**: Salted, iterated SHA-512 password scheme on Linux (`$6$…`); slower to crack than raw MD5/SHA-1.
- **Custom rules**: Rule DSL in `john.conf` that encodes human patterns (capitalize first, append digits/symbols); invoked with `--rule=<NAME>`.
