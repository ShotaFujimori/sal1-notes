# REMnux Getting Started — Cheat Sheet

## TL;DR

REMnux is a Linux distro preloaded with malware-analysis tools (Volatility, YARA, Wireshark, oledump, INetSim, etc.). Use it to analyze suspicious docs, simulate a fake network, and triage memory images safely—no fragile manual setup. 

---

## 1) File (Document) Analysis with `oledump.py`

**Goal:** Identify and extract VBA/macros from OLE/OOXML docs.
**Where your lab files live:** `~/Desktop/tasks/*` on the REMnux VM. 

### Commands

```bash
# Go to the sample doc directory
cd /home/ubuntu/Desktop/tasks/agenttesla/

# List OLE streams / macro indicators
oledump.py agenttesla.xlsm
```

You should see streams like `A: xl/vbaProject.bin` (macro-bearing).

## 3) Memory Forensics Triage with Volatility 3

**Goal:** Preprocess memory images quickly to enumerate processes, files, DLLs, suspicious regions.
**Plugins commonly used:** `windows.pstree.PsTree`, `windows.pslist.PsList`, `windows.cmdline.CmdLine`, `windows.filescan.FileScan`, `windows.dlllist.DllList`, `windows.malfind.Malfind`, `windows.psscan.PsScan`. 

### Commands

```bash
# Become root and navigate to the sample memory image
sudo su
cd /home/ubuntu/Desktop/tasks/Wcry_memory_image/

# Run per-plugin triage (wcry.mem is the image)
vol3 -f wcry.mem windows.pstree.PsTree
vol3 -f wcry.mem windows.pslist.PsList
vol3 -f wcry.mem windows.cmdline.CmdLine
vol3 -f wcry.mem windows.filescan.FileScan
vol3 -f wcry.mem windows.dlllist.DllList
vol3 -f wcry.mem windows.malfind.Malfind
vol3 -f wcry.mem windows.psscan.PsScan
```

(Expect each plugin to take ~2–3 minutes.)  

---

## 4) Recommended Analysis Workflow (Fast Triage)

1. **Static doc triage** with `oledump.py` to spot macros/indicators. 
2. **Dynamic network emulation** with INetSim to safely observe URLs/methods and captures. 
3. **Memory image preprocessing** with Volatility 3 to enumerate processes, files, DLLs, and suspicious memory regions. 
4. **Correlate findings** (e.g., macro’s URL ↔ network logs ↔ process tree).
5. **Pivot to deeper tooling** (YARA, Wireshark) as needed. 

---

## Gotchas (Read Me Before You Lab)

* **Paths matter:** Most task files live under `~/Desktop/tasks/...`; run commands in the right folder or you’ll get “file not found.” 
* **Volatility 3 runtime:** Plugins can feel “slow”—2–3 minutes each is normal; avoid killing the run too early. 
* **INetSim ≠ the Internet:** It emulates services; downloads are fake by design—use it to observe behavior, not to fetch real artifacts. 
* **Document types:** `oledump.py` targets OLE/OOXML; if the doc type differs, choose the right parser. 
* **Operate inside the VM:** The REMnux box is your sandbox—running samples outside increases risk.
