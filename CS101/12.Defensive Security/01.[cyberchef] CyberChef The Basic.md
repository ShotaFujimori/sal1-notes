# 40.SAL1 Note — CyberChef: The Basics (Cheat Sheet)
tags: [defensive, cyberchef, decoding, encoding, dfir, tooling]

## TL;DR
- CyberChef is a browser-based “Swiss-army knife” for transforming data with drag-and-drop **operations** arranged as a **recipe** that processes your **input** into **output**. :contentReference[oaicite:0]{index=0} :contentReference[oaicite:1]{index=1}
- Core workflow: set an objective → paste/upload data → choose operations (e.g., Base64/85, URL, ROT) → check output; iterate until the goal is met. :contentReference[oaicite:2]{index=2} :contentReference[oaicite:3]{index=3}
- You can **BAKE!** recipes manually or enable **Auto Bake** for live updates; save/load recipes for reuse. :contentReference[oaicite:4]{index=4} :contentReference[oaicite:5]{index=5}

## Interface Quick Map
- **Operations**: searchable list of transforms (e.g., “From Base64”, “URL Decode”, “ROT13”). :contentReference[oaicite:6]{index=6}
- **Recipe**: the ordered list you build; supports save/load/clear and Auto Bake. :contentReference[oaicite:7]{index=7} :contentReference[oaicite:8]{index=8} :contentReference[oaicite:9]{index=9}
- **Input**: paste, type, or upload file/folder; can add multiple input tabs. :contentReference[oaicite:10]{index=10}

## Common Operations (with quick examples)
> Use the search bar in **Operations** to find these. Hovering shows tips and links. :contentReference[oaicite:13]{index=13}

- **From Base64** → decode Base64 strings.  
  Example: `V2VsY29tZSB0byB0cnloYWNrbWUh` → `Welcome to tryhackme!` :contentReference[oaicite:14]{index=14}
- **URL Decode** → turn `%`-encoded bytes back to text.  
  Example: `https%3A%2F%2Fgchq%2Egithub%2Eio%2FCyberChef%2F` → `https://gchq.github.io/CyberChef/` :contentReference[oaicite:15]{index=15}
- **From Base85** → decode ASCII Base85 (often shorter than Base64).  
  Example: `BOu!rD]j7BEbo7` → `hello world` :contentReference[oaicite:16]{index=16}
- **To Hex / To Decimal** → show byte values in hex/decimal. :contentReference[oaicite:17]{index=17} :contentReference[oaicite:18]{index=18}
- **ROT13** → simple Caesar rotation; sanity-check “gibberish”. :contentReference[oaicite:19]{index=19}
- **Extractors** → pull **IPs/URLs/emails** from blobs of text/logs. :contentReference[oaicite:20]{index=20}
- **Date/Time** → convert **UNIX timestamps** ↔ readable time. :contentReference[oaicite:21]{index=21}

## Typical Mini-Recipes
> Drag operations into **Recipe**, set arguments if needed, then **BAKE!**.

- **Decode a Base64 URL parameter**  
  `URL Decode` → `From Base64` → (optionally) `To Hex`  
  Why: URL params often double-encoded (URL then Base64). :contentReference[oaicite:22]{index=22} :contentReference[oaicite:23]{index=23}

- **Locate IOCs inside text**  
  `Extract IP addresses` + `Extract URLs` + `Extract email addresses`  
  Why: fast triage of artifacts in DFIR notes/logs. :contentReference[oaicite:24]{index=24}

- **Timestamp sanity-check**  
  `From UNIX Timestamp` ↔ `To UNIX Timestamp`  
  Why: pivot between logs using epoch vs human time. :contentReference[oaicite:25]{index=25}

## Workflow (Repeatable)
1) **Objective**: define “what do I want to accomplish?”  
2) **Input**: paste/upload raw data.  
3) **Operations**: pick candidate transforms (Encoding/Decoding often first).  
4) **Output**: verify result; iterate if it’s not right. :contentReference[oaicite:26]{index=26} :contentReference[oaicite:27]{index=27}

## Gotchas
- **Order matters**: Recipes run top-to-bottom; wrong order = garbage output. (Use **Auto Bake** to iterate faster.) :contentReference[oaicite:31]{index=31}
- **Encoding vs Encryption**: Operations like Base64/85 and ROT are **encodings**, not security; don’t treat them as crypto. :contentReference[oaicite:32]{index=32}
- **False positives** with Extractors if the input is noisy; validate results before acting. :contentReference[oaicite:33]{index=33}
- **Timezone pitfalls**: When flipping timestamps, note UTC assumptions in conversions. :contentReference[oaicite:34]{index=34}
