# 40.SAL1 Note — CyberChef: The Basics (Cheat Sheet)
tags: [defensive, cyberchef, decoding, encoding, dfir, tooling]

## TL;DR
- CyberChef is a browser-based “Swiss-army knife” for transforming data with drag-and-drop **operations** arranged as a **recipe** that processes your **input** into **output**.
- Core workflow: set an objective → paste/upload data → choose operations (e.g., Base64/85, URL, ROT) → check output; iterate until the goal is met. 
- You can **BAKE!** recipes manually or enable **Auto Bake** for live updates; save/load recipes for reuse.

---

## Interface Quick Map
- **Operations**: searchable list of transforms (e.g., “From Base64”, “URL Decode”, “ROT13”).
- **Recipe**: the ordered list you build; supports save/load/clear and Auto Bake. 
- **Input**: paste, type, or upload file/folder; can add multiple input tabs. 
- **Output**: processed result; copy/save/replace input; maximize pane.

---

## Common Operations (with quick examples)
> Use the search bar in **Operations** to find these. Hovering shows tips and links.

- **From Base64** → decode Base64 strings.  
  Example: `V2VsY29tZSB0byB0cnloYWNrbWUh` → `Welcome to tryhackme!` 
- **URL Decode** → turn `%`-encoded bytes back to text.  
  Example: `https%3A%2F%2Fgchq%2Egithub%2Eio%2FCyberChef%2F` → `https://gchq.github.io/CyberChef/` 
- **From Base85** → decode ASCII Base85 (often shorter than Base64).  
  Example: `BOu!rD]j7BEbo7` → `hello world` 
- **To Hex / To Decimal** → show byte values in hex/decimal. 
- **ROT13** → simple Caesar rotation; sanity-check “gibberish”. 
- **Extractors** → pull **IPs/URLs/emails** from blobs of text/logs. 
- **Date/Time** → convert **UNIX timestamps** ↔ readable time. 

---

## Typical Mini-Recipes
> Drag operations into **Recipe**, set arguments if needed, then **BAKE!**.

- **Decode a Base64 URL parameter**  
  `URL Decode` → `From Base64` → (optionally) `To Hex`  
  Why: URL params often double-encoded (URL then Base64). 
- **Locate IOCs inside text**  
  `Extract IP addresses` + `Extract URLs` + `Extract email addresses`  
  Why: fast triage of artifacts in DFIR notes/logs. 

- **Timestamp sanity-check**  
  `From UNIX Timestamp` ↔ `To UNIX Timestamp`  
  Why: pivot between logs using epoch vs human time.

---

## Workflow (Repeatable)
1) **Objective**: define “what do I want to accomplish?”  
2) **Input**: paste/upload raw data.  
3) **Operations**: pick candidate transforms (Encoding/Decoding often first).  
4) **Output**: verify result; iterate if it’s not right.

---

## Quick Practice Targets (from room checks)
- Base64 of `"Nice Room!"` → `TmljZSBSb29tIQ==` (confirm your pipeline). 
- URL-decode `https%3A%2F%2Ftryhackme%2Ecom%2Fr%2Froom%2Fcyberchefbasics`. 
- Convert UNIX `1725151258` → human time. 

---

## Gotchas
- **Order matters**: Recipes run top-to-bottom; wrong order = garbage output. (Use **Auto Bake** to iterate faster.) 
- **Encoding vs Encryption**: Operations like Base64/85 and ROT are **encodings**, not security; don’t treat them as crypto.
- **False positives** with Extractors if the input is noisy; validate results before acting.
- **Timezone pitfalls**: When flipping timestamps, note UTC assumptions in conversions.
