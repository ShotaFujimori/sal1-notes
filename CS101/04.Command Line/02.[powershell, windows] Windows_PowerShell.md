# SAL1/windows\_powershell.md

tags: \[powershell, windows]

## TL;DR

* PowerShell is an **object-oriented** shell: pipelines pass objects, not text—so filtering and formatting are robust.
* Use **Verb-Noun** cmdlets and discover fast with `Get-Help -Examples` and `Get-Command`.
* Added **Priv** column below to surface **User/Admin** requirements at a glance; removed accidental extra column by ensuring each row has exactly six cells and escaping pipeline symbols.

## Gotchas

* **Admin** typically required for: service control, remoting setup, firewall changes, local account/group management, reboot, and reading **Security** log.
* `Set-ExecutionPolicy` can be **CurrentUser** (no admin) or **LocalMachine** (admin).
* File operations to protected paths (e.g., `C:\Windows\…`) require admin; prefer working under user profile.
* `Stop-Process` can kill only your processes without elevation; others require admin.
