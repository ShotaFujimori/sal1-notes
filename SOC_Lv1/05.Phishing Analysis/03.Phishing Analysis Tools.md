# 🛠️ Phishing Analysis Tools — Exam Prep Cheat Sheet

> **TL;DR:** Phishing analysis follows a structured artifact-collection workflow: header → body → URLs → attachments. Each stage has dedicated tools (Messageheader, IPinfo, URLScan, VirusTotal, ANY.RUN, PhishTool) that automate and safely perform the analysis without interacting with malicious content directly.

---

## ⚠️ Gotchas

| Gotcha | Detail |
|---|---|
| Never open attachments directly | Always use a VM, sandbox, or controlled environment |
| Hash before analyzing | Generate SHA256 first — use hash for reputation lookups, not the file |
| Uploading to VirusTotal/ANY.RUN is public | Sensitive files may be exposed; use hash lookup when possible |
| `sha256sum` output order | Hash is printed **first**, filename **second** |
| URLScan.io submissions are public | The scanned URL and screenshot become publicly visible |
| Talos classifies by reputation | "Neutral" ≠ safe — it just means no known malicious activity yet |
| PhishTool Resolve ≠ delete | Resolving documents findings for SOC records; email is not removed |
| CVE-2017-11882 is a common vector | Old Microsoft Equation Editor exploit — still actively used in `.xlsx` attacks |

## 📋 Artifact Collection — What to Collect

### Header Artifacts
| Artifact | What It Tells You |
|---|---|
| Sender email address | Origin of the email; check display name vs actual address |
| Sender IP address | Reverse lookup reveals hosting org and geography |
| Email subject line | Urgency/call-to-action signals |
| Recipient address (To/CC/BCC) | Who is targeted; BCC hides victim list |
| Reply-To address | Where responses go — often different from sender |
| Date and time | Timing context; urgency checks (same-day expiry) |

### Body Artifacts
| Artifact | What It Tells You |
|---|---|
| URLs and hyperlinks | Expand shortened URLs; find true destination |
| Attachment name(s) | Suspicious names or unexpected file extensions |
| Attachment hash (SHA256) | Use for threat intelligence lookups without opening the file |

## 🗂️ Tool Selection Guide — When to Use What

| Situation | Best Tool(s) |
|---|---|
| Need sender IP from raw headers | Messageheader / Message Header Analyzer |
| Want geo/org info for an IP | IPinfo |
| Need to check reputation of a domain | Talos + VirusTotal |
| Want to safely browse a suspicious URL | URLScan.io |
| Need to check if a file is known malware | VirusTotal (hash lookup) |
| Need to safely run a suspicious file | ANY.RUN / Hybrid Analysis / JOESandbox |
| Need to extract all URLs from email body | CyberChef / URL Extractor |
| Want full end-to-end phishing investigation | PhishTool |
| Need to document and resolve a SOC case | PhishTool → Resolve |

## 💻 Commands — Linux

### Generate SHA256 Hash of Attachment
```bash
sha256sum shady_attachment.pdf
# Output:
# 025ba9ce4a2118a9ca7b115c8869ff73bc16bad3732ba359cef1e60ad8f961f9  shady_attachment.pdf
# Format: <hash>  <filename>
```

### Generate SHA256 for Multiple Files
```bash
sha256sum *.pdf
sha256sum file1.xlsx file2.dot
```

### Verify a Known Hash (integrity check)
```bash
echo "025ba9ce4a2118a9ca7b115c8869ff73bc16bad3732ba359cef1e60ad8f961f9  shady_attachment.pdf" | sha256sum -c
# Output: shady_attachment.pdf: OK
```

### Other Hash Commands (for reference)
```bash
md5sum    attachment.pdf   # MD5  (weaker, still used in some intel feeds)
sha1sum   attachment.pdf   # SHA1 (deprecated but sometimes required)
sha256sum attachment.pdf   # SHA256 (current standard for threat intel)
```

## 📧 Task 3 — Email Header Analysis

### Header Analysis Tools Comparison
| Feature | Messageheader (Google) | Message Header Analyzer |
|---|---|---|
| Provider | Google Admin Toolbox | Microsoft/Community |
| Input | Paste raw header | Paste raw header |
| Output | Sender IP, routing, delay, SPF/DKIM | Summary, received headers, other headers |
| Highlights | Flags delivery delays (red) | Shows hop-by-hop path |
| Best for | Quick SPF/DKIM check | Detailed routing investigation |

### Key Header Fields to Investigate
| Field | Purpose | Red Flag |
|---|---|---|
| `From:` | Sender display name + actual address | Display name ≠ actual address |
| `Reply-To:` | Where replies are directed | Different domain from `From:` |
| `Received:` | Routing hops (bottom = origin) | Unknown or suspicious relay |
| `X-Originating-IP:` | Original sending IP | IP in suspicious geo/org |
| `Return-Path:` | Bounce-back address | Different domain from sender |
| `SPF:` | Sender Policy Framework result | `fail` or `softfail` |
| `DKIM:` | Email signature result | `fail` or `permerror` |
| `DMARC:` | Policy alignment result | `fail` |

| Question | Answer |
|---|---|
| Web reputation of `malware-test.com` on Talos? | **Neutral** |

## 📎 Task 4 — Email Body & Attachment Analysis

### URL Extraction Methods
| Method | How | Best For |
|---|---|---|
| Right-click → Copy link address | In email client or browser | Quick single-link check |
| View raw HTML source | `View > Message Source` in Thunderbird | Finding hidden/obfuscated URLs |
| CyberChef URL extractor | Paste raw content; auto-parses all URLs | Bulk URL extraction |
| Online URL extractor tool | Paste raw email; click Extract | Fast batch extraction |

### Attachment Analysis Workflow
| Step | Action | Tool/Command |
|---|---|---|
| 1 | Download to sandbox/VM only | Virtual machine or sandboxed environment |
| 2 | Generate SHA256 hash | `sha256sum <filename>` |
| 3 | Look up hash on Talos | Talos IP & Domain Reputation Center |
| 4 | Look up hash on VirusTotal | virustotal.com → Search by hash |
| 5 | Run in sandbox if needed | ANY.RUN / Hybrid Analysis / JOESandbox |

### Talos File Hash Result Labels
| Label | Meaning |
|---|---|
| Phishing | File is associated with phishing activity |
| Malicious | File is confirmed as malware |
| Spam | File is associated with spam campaigns |
| Clean | No known malicious activity |
| Unknown | No data available |

## 🔁 Full Phishing Analysis Workflow

```
1. RECEIVE suspicious email
        │
        ▼
2. COLLECT HEADER ARTIFACTS
   ├── Sender address (display name vs actual)
   ├── Sender IP → IPinfo lookup
   ├── Reply-To / Return-Path domain
   └── Paste header → Messageheader / MHA tool
        │
        ▼
3. COLLECT BODY ARTIFACTS
   ├── Extract all URLs (CyberChef / URL Extractor)
   ├── Expand shortened URLs (WhereGoes)
   └── Check URL reputation (URLScan.io / Talos / VirusTotal)
        │
        ▼
4. ANALYZE ATTACHMENTS (in sandbox only)
   ├── sha256sum <file>
   ├── Look up hash on Talos / VirusTotal
   └── Run in ANY.RUN / Hybrid Analysis / JOESandbox
        │
        ▼
5. DOCUMENT & RESOLVE (PhishTool)
   ├── Flag artifacts
   ├── Set disposition (Malicious / Spam / Legitimate)
   ├── Add classification code (MAL_URL, etc.)
   ├── Write notes
   └── Click Resolve
```
