# 🎣 Snapped Phish-ing Line — Reference Sheet

> **TL;DR:** A multi-victim phishing campaign targeting SwiftSpend Financial employees. Adversary sends credential-harvesting emails, hosts a phishing kit (disguised as Microsoft login) on an exposed web server, and collects credentials via `submit.php` → Yandex email. Investigation involves email artifact extraction, URL redirection tracing, phishing kit download/analysis, directory enumeration, hash lookup, and CyberChef decoding.

---

## ⚠️ Gotchas

| Gotcha | Detail |
|---|---|
| Attachment ≠ direct phishing URL | The attachment contains a redirect URL — trace the full chain |
| Attacker left `/data` directory exposed | Always enumerate common directories on phishing domains |
| `.zip` phishing kit = also classified as Trojan | VirusTotal may flag it under multiple threat categories |
| `submit.php` reveals attacker's collection email | Extracting and reading kit source code exposes backend infrastructure |
| Log files in `/data/Update365/` contain real victims | Check logs for repeated submissions = likely real compromised accounts |
| CyberChef needed for encoded flag | `flag.txt` is encoded — use CyberChef to decode |
| `.icu` TLD is heavily abused for phishing | Non-standard TLDs like `.icu`, `.buzz`, `.xyz` are common phishing indicators |
| File count inside archive matters | 49 files in the kit indicates a well-prepared, structured phishing operation |

## 🔍 Full Investigation Workflow

```
1. Review emails in phish-emails folder
   ├─ Identify recipients and subjects
   └─ Extract sender address

2. Investigate email attachment (Zoe Duncan's email)
   ├─ Open attachment safely
   ├─ Extract redirection URL
   └─ Identify root domain

3. Open phishing URL in VM browser
   ├─ Identify impersonated brand
   └─ Enumerate exposed directories

4. Navigate to /data directory
   ├─ Locate archive file (Update365.zip)
   └─ Download to VM

5. Hash the downloaded archive
   └─ sha256sum Update365.zip

6. VirusTotal lookup
   ├─ Threat categories (phishing + Trojan)
   └─ File count inside archive (Details tab)

7. Check /data/Update365/ for logs
   └─ Identify repeat credential submitters

8. Extract archive and analyze submit.php
   └─ Find attacker's collection email address

9. Find flag.txt on phishing URL
   └─ Decode with CyberChef
```

## 📦 Step 4 — Phishing Kit Archive Analysis

### Archive Details
| Field | Value |
|---|---|
| **Filename** | `Update365.zip` |
| **Location found** | `/data/` directory on phishing server |
| **SHA256 hash** | `ba3c15267393419eb08c7b2652b8b6b39b406ef300ae8a18fee4d16b19ac9686` |
| **VirusTotal categories** | **Phishing** + **Trojan** |
| **File count inside archive** | **49 files** |

### Commands — Hash & Extract
```bash
# Step 1: Generate SHA256 hash
sha256sum Update365.zip
# Output:
# ba3c15267393419eb08c7b2652b8b6b39b406ef300ae8a18fee4d16b19ac9686  Update365.zip

# Step 2: Extract the archive
unzip Update365.zip -d Update365/

# Step 3: List all extracted files
ls -la Update365/
find Update365/ -type f | sort

# Step 4: Read submit.php to find collection address
cat Update365/submit.php | grep -i "mail\|email\|yandex\|send"

# Step 5: Read credential log
cat /data/Update365/<logfile>
# or after download:
cat Update365/<logfile>.txt
```

### VirusTotal Lookup Steps

## 🔓 Step 7 — Flag Decoding with CyberChef

### Find and Decode the Flag
```
1. Navigate to: http://kennaroads.buzz/flag.txt
2. Copy the encoded string
3. Go to: https://gchq.github.io/CyberChef/
4. Paste encoded value into Input
5. Apply appropriate decoding operation (e.g., Base64, URL decode, ROT13)
6. Read decoded output
```

### Flag Result
| Field | Value |
|---|---|
| **URL** | `http://kennaroads.buzz/flag.txt` |
| **Decoded value** | `THM{pL4y_w1Th_tH3_URL}` |

### Common CyberChef Operations for CTF Flags
| Operation | When to Use |
|---|---|
| From Base64 | Encoded with `=` padding, A-Z a-z 0-9 +/ chars |
| URL Decode | `%XX` encoded characters |
| ROT13 | Shifted alphabet characters |
| From Hex | `0x` or space-separated hex values |
| Magic | Auto-detect encoding type |
