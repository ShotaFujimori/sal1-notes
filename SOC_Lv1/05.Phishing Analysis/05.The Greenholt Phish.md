# 🎣 The Greenholt Phish — Reference Sheet

> **TL;DR:** A BEC (Business Email Compromise)-style phishing email targeting Greenholt PLC, impersonating a known customer to request a money transfer via a malicious `.CAB` attachment (actually a RAR archive). Full analysis workflow: header artifacts → IP/SPF/DMARC lookups → SHA256 hash → VirusTotal file type check.

---

## ⚠️ Gotchas

| Gotcha | Detail |
|---|---|
| `Reply-To` ≠ `From` | Attacker directs replies to a different address (`info.mutawamarine@mail.com`) to intercept responses |
| `.CAB` extension ≠ actual file type | VirusTotal reveals the true file type is **RAR** — extension spoofing is common |
| Known sender ≠ safe | The email claims to be from a known customer; BEC attacks exploit existing trust relationships |
| Generic greeting = red flag | "Dear Sir/Madam" style greetings from a "known contact" indicate spoofing |
| `SPF -all` ≠ protection if DMARC is weak | SPF may reject unauthorized senders, but `p=quarantine` (not `p=reject`) still lets some through |
| IP owner ≠ attacker | Hostwinds LLC is a hosting provider; the attacker is a customer using their infrastructure |
| SHA256 hash lookup is safer than running the file | Never execute unknown attachments; use hash for VirusTotal lookups |
| File size on VirusTotal may differ from local size | VirusTotal reports the analyzed file's size — note the unit (KB) |

## 🔍 Full Investigation Workflow

```
1. Read email body
   └─ Note subject line, greeting style, request type, attachment presence

2. Collect header artifacts
   ├─ Subject line / Transfer Reference Number
   ├─ Display name vs actual From: address
   ├─ Reply-To address (different from From?)
   └─ Originating IP (Received: header)

3. IP reputation lookup
   └─ IPinfo → identify owner/org of originating IP

4. DNS authentication checks
   ├─ SPF record lookup on Return-Path domain
   └─ DMARC record lookup on Return-Path domain

5. Attachment analysis
   ├─ Note filename and extension
   ├─ Download to sandbox/VM only
   ├─ sha256sum <filename>  → get hash
   └─ VirusTotal hash lookup → file size, true file type, detections
```

## 🔐 Step 3 — SPF Record Check

### Tool: SPF Surveyor (dmarcian) or `nslookup`/`dig`
```bash
# CLI lookup of SPF record for Return-Path domain
nslookup -type=TXT mutawamarine.com
# or
dig TXT mutawamarine.com +short
```

### SPF Record Result
| Field | Value |
|---|---|
| **Domain checked** | Return-Path domain (`mutawamarine.com`) |
| **Full SPF record** | `v=spf1 include:spf.protection.outlook.com -all` |

### SPF Record Breakdown
| Component | Meaning |
|---|---|
| `v=spf1` | SPF version 1 — standard |
| `include:spf.protection.outlook.com` | Authorizes Microsoft/Office 365 mail servers |
| `-all` | Hard fail — all other senders explicitly rejected |

### SPF Result Interpretation
| Fact | Implication |
|---|---|
| `-all` is used | Only Office 365 servers authorized — any other IP should fail SPF |
| Originating IP is `192.119.71.157` (Hostwinds) | Not in Office 365 IP range → **SPF would fail** |
| Email still reached the inbox | Receiving server may not enforce SPF strictly, or attacker found a bypass |

## 🏛️ Step 4 — DMARC Record Lookup

### Tool: dmarcian Domain Checker or `dig`
```bash
# CLI lookup of DMARC record
dig TXT _dmarc.mutawamarine.com +short
# or
nslookup -type=TXT _dmarc.mutawamarine.com
```

### DMARC Record Result
| Field | Value |
|---|---|
| **Domain checked** | `_dmarc.mutawamarine.com` |
| **Full DMARC record** | `v=DMARC1; p=quarantine; fo=1` |

### DMARC Record Breakdown
| Tag | Value | Meaning |
|---|---|---|
| `v=` | `DMARC1` | DMARC version (required) |
| `p=` | `quarantine` | Failing emails moved to spam — not fully rejected |
| `fo=` | `1` | Generate forensic reports when SPF or DKIM fails (either one) |

### DMARC Policy Comparison (for context)
| Policy | Action on Failure | Protection Level |
|---|---|---|
| `p=none` | No action; monitor only | ⭐ Weakest |
| `p=quarantine` | Move to spam/junk | ⭐⭐ Medium ← **this domain** |
| `p=reject` | Block and discard | ⭐⭐⭐ Strongest |

### `fo=` Forensic Reporting Options
| Value | When Reports Are Generated |
|---|---|
| `0` | Only when both SPF and DKIM fail (default) |
| `1` | When **either** SPF or DKIM fails |
| `d` | Only when DKIM fails |
| `s` | Only when SPF fails |

## 📎 Step 5 — Attachment Analysis

### Attachment Details
| Field | Value |
|---|---|
| **Filename** | `SWT_#09674321____PDF__.CAB` |
| **Claimed extension** | `.CAB` (Windows Cabinet archive) |
| **True file type** | **RAR** archive |
| **SHA256 hash** | `2e91c533615a9bb8929ac4bb76707b2444597ce063d84a4b33525e25074fff3f` |
| **File size (VirusTotal)** | **400.26 KB** |

### Why the Filename Is Suspicious
| Red Flag | Detail |
|---|---|
| `____PDF____` in filename | Tricks user into thinking it's a PDF document |
| `.CAB` extension | Unusual file type for a legitimate business document |
| True type is RAR | Extension spoofing — actual content hidden from casual inspection |
| Reference number in filename | `#09674321` matches subject line — designed to appear legitimate |

### Commands — Attachment Hash
```bash
# Generate SHA256 hash of the attachment (in VM/sandbox only)
sha256sum SWT_#09674321____PDF__.CAB
# Output:
# 2e91c533615a9bb8929ac4bb76707b2444597ce063d84a4b33525e25074fff3f  SWT_#09674321____PDF__.CAB

# Verify hash format: 64 hex characters = SHA256
echo "2e91c533615a9bb8929ac4bb76707b2444597ce063d84a4b33525e25074fff3f" | wc -c
# Output: 65 (64 chars + newline)
```

### VirusTotal Hash Lookup
```
# Navigate to: https://www.virustotal.com
# Search: 2e91c533615a9bb8929ac4bb76707b2444597ce063d84a4b33525e25074fff3f
# Check:
#   - File size (Details tab)
#   - File type (Details tab → Magic / Type)
#   - Detection ratio (Detection tab)
#   - Threat label / family
```

### VirusTotal Key Fields to Note
| Field | Location in VT | Value Found |
|---|---|---|
| File size | Details tab | **400.26 KB** |
| File type | Details tab → Magic | **RAR** |
| Detection ratio | Detection tab | Number of vendors flagging as malicious |
| Threat label | Detection tab | Phishing / Trojan / etc. |
| SHA256 | Details tab | Confirmed hash |
