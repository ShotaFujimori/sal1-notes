# 🗺️ Nmap — Reference Sheet

> **TL;DR:** Nmap is a port scanner. It works out which of the 65,535 TCP/UDP ports on a target are open, what service and OS sit behind them, and runs NSE (Lua) scripts for extra checks. The main scan types are **-sT** (full connect), **-sS** (half-open SYN, needs sudo) and **-sU** (UDP). **-sN / -sF / -sX** are stealthier scans used for firewall evasion. Add **-Pn** when the target blocks ICMP ping.

---

## ⚠️ Gotchas

| Gotcha | Detail |
|---|---|
| "Host seems down" ≠ down | Nmap pings before scanning. If ICMP is blocked it gives up, so add **-Pn** to skip host discovery |
| -sS needs root | SYN scan crafts raw packets, so you need `sudo`. Without root Nmap falls back to **-sT** |
| `open\|filtered` is not "open" | Means no response came back, so Nmap can't tell open from firewalled. Normal for UDP, NULL, FIN and Xmas scans |
| Xmas/UDP scans are slow | No response means Nmap waits for a timeout on every port. Add `-v` to see that it's still running |
| Windows breaks NULL/FIN/Xmas | Windows replies **RST to every port**, so all ports look closed |
| `-p-` = all ports | Same as `-p 1-65535`. By default Nmap scans only the top 1000 ports |
| -oA vs -oN | **-oA** saves all three major formats at once; **-oN** is normal format only |
| Category vs pattern | `--script=vuln` runs the whole category (no `*`). `--script=*vuln*` matches script names |
| Intrusive scripts | Never run `intrusive` (or `exploit`/`dos`) scripts against production systems |
| Higher -T = noisier | `-T5` is fast but loud and loses accuracy; `-T0` is extremely slow |
| ftp-anon TIMEOUT | `Can't get directory listing: TIMEOUT` still means login **succeeded** (code 230) |
| RFC 793 is obsolete | TCP is now defined in **RFC 9293** |

## 2️⃣ Task 3 — Nmap Switches

### Help lookup

**Purpose:** Find any switch quickly.

```bash
nmap -h | grep -i udp        # -sU: UDP Scan
nmap -h | grep -i "os"       # -O: Enable OS detection
nmap -h | grep -i verbosity  # -v / -vv
man nmap                     # full manual
```

### Switch table

| Goal | Switch |
|---|---|
| SYN scan | **-sS** |
| TCP connect scan | **-sT** |
| UDP scan | **-sU** |
| NULL / FIN / Xmas scan | **-sN / -sF / -sX** |
| Ping sweep (no port scan) | **-sn** |
| Skip host discovery | **-Pn** |
| OS detection | **-O** |
| Service version detection | **-sV** |
| Verbosity 1 / 2 | **-v / -vv** |
| Save in 3 major formats | **-oA** |
| Save normal output | **-oN** |
| Save grepable output | **-oG** |
| Save XML output | -oX |
| Aggressive mode (-sV, -O, traceroute, default scripts) | **-A** |
| Timing template 5 | **-T5** |
| Port 80 only | **-p 80** |
| Ports 1000–1500 | **-p 1000-1500** |
| All ports | **-p-** |
| Run a script | **--script** |
| All "vuln" category scripts | **--script=vuln** |

### Timing templates

| Level | Name | Use |
|---|---|---|
| -T0 | paranoid | IDS evasion, extremely slow |
| -T1 | sneaky | IDS evasion |
| -T2 | polite | Low bandwidth |
| -T3 | normal | Default |
| -T4 | aggressive | Common in CTFs |
| -T5 | insane | Fastest, least accurate |

### Typical full command

```bash
sudo nmap -sS -sV -O -p- -T4 -vv -oA scan_results MACHINE_IP
# SYN scan all ports, detect versions + OS, verbose, save as .nmap/.gnmap/.xml
```

## 4️⃣ Tasks 5–8 — Scan Types Compared

### TCP flag responses

| Scan | Packet sent | Open | Closed | Filtered |
|---|---|---|---|---|
| **-sT** Connect | SYN, then full handshake | SYN/ACK → ACK (connection completed, then RST/ACK) | RST | No response |
| **-sS** SYN | SYN | SYN/ACK → **RST** (handshake never completed) | RST | No response |
| **-sU** UDP | UDP packet | UDP reply (rare) or none → `open\|filtered` | **ICMP port unreachable** | No response → `open\|filtered` |
| **-sN** NULL | No flags | No response → `open\|filtered` | RST | ICMP unreachable |
| **-sF** FIN | FIN | No response → `open\|filtered` | RST | ICMP unreachable |
| **-sX** Xmas | FIN + PSH + **URG** | No response → `open\|filtered` | RST | ICMP unreachable |

### Connect vs SYN

| | -sT Connect | -sS SYN (Half-open / Stealth) |
|---|---|---|
| Handshake | Full 3-way | Half: sends RST instead of the final ACK |
| Privileges | Any user | **Root/sudo** required |
| Logged by apps | Yes (full connection) | Less likely |
| Speed | Slower | Faster |
| Risk | Safe | Can crash unstable services |
| Default | When not root | When root |

### Wireshark view of -sT (port 80)

```text
AttackBox → Target : SYN
Target → AttackBox : SYN, ACK
AttackBox → Target : ACK        ← handshake completed
AttackBox → Target : RST, ACK   ← Nmap tears it down
```

Display filter: `tcp.port == 80 && ip.addr == MACHINE_IP`

### Q&A

| Question | Answer |
|---|---|
| RFC defining TCP behaviour | **RFC 9293** |
| Flag returned for a closed port | **RST** |
| Other names for SYN scan | **Half-Open, Stealth** |
| SYN scan without sudo? | **N** |
| UDP port with no response is marked | **open\|filtered** |
| Protocol for UDP "port unreachable" | **ICMP** |
| Scan type using URG flag | **Xmas** |
| Why use NULL/FIN/Xmas | **Firewall evasion** |
| OS replying RST to every port | **Microsoft Windows** |

## 5️⃣ Task 9 — ICMP Network Scanning (Ping Sweep)

**Purpose:** Find live hosts on a subnet without scanning ports.

```bash
nmap -sn 172.16.0.0/16
# -sn = host discovery only (ICMP echo + TCP 443 SYN + TCP 80 ACK; ARP on local LAN)
# /16 = netmask 255.255.0.0
nmap -sn 192.168.0.1-254   # range notation also works
```

| Question | Answer |
|---|---|
| Ping sweep 172.16.x.x (255.255.0.0) | **nmap -sn 172.16.0.0/16** |

## 6️⃣ Tasks 10–12 — NSE (Nmap Scripting Engine)

### Concepts

| Item | Detail |
|---|---|
| Language | **Lua** |
| Location | `/usr/share/nmap/scripts/` |
| Index | `/usr/share/nmap/scripts/script.db` |
| Docs | nmap.org/nsedoc |

### Script categories

| Category | Purpose |
|---|---|
| safe | Won't affect the target |
| **intrusive** | Likely to affect the target. **Never run in production** |
| vuln | Scan for vulnerabilities |
| exploit | Attempt to exploit |
| auth | Bypass/check authentication (e.g. ftp-anon) |
| brute | Brute-force credentials |
| discovery | Query services for more info (e.g. SNMP, SMB) |
| default | Run by `-sC` / `-A` |

### Running scripts

```bash
nmap --script=vuln MACHINE_IP                        # whole category
nmap --script=http-fileupload-exploiter MACHINE_IP   # single script
nmap --script=smb-enum-users,smb-enum-shares MACHINE_IP   # multiple
nmap -p 80 --script http-put --script-args http-put.url='/dav/shell.php',http-put.file='./shell.php' MACHINE_IP
nmap --script-help ftp-anon                          # script help
```

### Searching for scripts

```bash
grep "smb" /usr/share/nmap/scripts/script.db     # method 1: script.db
ls -l /usr/share/nmap/scripts/*smb*              # method 2: ls with wildcard
grep "dependencies" /usr/share/nmap/scripts/smb-os-discovery.nse
sudo nmap --script-updatedb                      # refresh after adding a script
```

### Pattern matching

| Goal | Command |
|---|---|
| All scripts in "vuln" category | `--script=vuln` |
| Script names containing "vuln" | `--script=*vuln*` |
| Script names starting with "http" | `--script=http*` |

### Q&A

| Question | Answer |
|---|---|
| NSE script language | **Lua** |
| Category not to run in production | **intrusive** |
| Optional argument for ftp-anon.nse | **maxlist** |
| SMB script determining the OS | **smb-os-discovery.nse** |
| What smb-os-discovery depends on | **smb-brute** ⚠️ blank in your notes; this is the standard answer, so check with `grep dependencies` |

## 7️⃣ Task 13 — Firewall Evasion

| Switch | Purpose |
|---|---|
| **-Pn** | Skip ping; treat host as up (needed when **ICMP** is blocked) |
| -f | Fragment packets (harder for IDS to inspect) |
| --mtu <n> | Custom fragment size (multiple of 8) |
| --scan-delay <time>ms | Delay between packets (evade time-based IDS) |
| --badsum | Send invalid checksums (a real stack drops them, so a reply means a firewall answered) |
| **--data-length <n>** | Append random data of arbitrary length to packets |

| Question | Answer |
|---|---|
| Commonly blocked protocol requiring -Pn | **ICMP** |
| Switch to append random data | **--data-length** |

## 8️⃣ Task 14 — Practical

Target: Windows host that ignores ping. Open ports: **21/ftp, 53/domain, 80/http, 135/msrpc, 3389/ms-wbt-server**.

### Confirm ping is blocked

```bash
ping MACHINE_IP                # no replies → ICMP blocked
nmap -Pn MACHINE_IP            # still finds open TCP ports → host alive
```

### Xmas scan, first 999 ports

```bash
nmap -sX -Pn -p 1-999 -v MACHINE_IP
# All 999 ports: open|filtered   reason: no-response
nmap -sX -Pn -p 1-999 MACHINE_IP | grep "open|filtered" | wc -l   # count
```

### SYN scan, first 5000 ports

```bash
sudo nmap -sS -Pn -p 1-5000 -v MACHINE_IP
# 5 open ports
```

### TCP connect + Wireshark, then ftp-anon

```bash
nmap -sT -Pn -p 80 MACHINE_IP
nmap -Pn -p 21 --script ftp-anon -vv MACHINE_IP
# | ftp-anon: Anonymous FTP login allowed (FTP code 230)
# |_Can't get directory listing: TIMEOUT   ← login still succeeded
```

### Q&A

| Question | Answer |
|---|---|
| Target responds to ICMP echo? | **N** |
| Xmas scan first 999 ports: open\|filtered count | **999** |
| Reason given | **No Response** |
| SYN scan first 5000 ports: open count | **5** |
| Can Nmap log in to FTP on 21 (ftp-anon)? | **Y** |
