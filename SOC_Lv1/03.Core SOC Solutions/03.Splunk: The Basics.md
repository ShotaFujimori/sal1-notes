# Splunk: The Basics — Quick Cheat Sheet

## TL;DR

* **Forwarder**: collects logs and sends them to Splunk.
* **Indexer**: parses, normalizes, and stores logs as searchable events.
* **Search Head**: where you search data using **SPL**.
* Main flow: **Collect → Index → Search → Analyze → Visualize**
* In the lab, VPN logs are uploaded into index **`VPN_Logs`**. 

---

## 1) Core Components

### Forwarder

**Role:** Collects data from endpoints and forwards it.

**Example SPL**

```spl
index=VPN_Logs
```

**Explanation:**
Shows events after logs have been collected and indexed.

**Concrete example**

```spl
index=VPN_Logs earliest=-24h
```

---

### Indexer

**Role:** Processes incoming logs into searchable events.

**Example SPL**

```spl
index=VPN_Logs | head 10
```

**Explanation:**
Quick check that data exists in the index.

**Concrete example**

```spl
index=VPN_Logs | table _time host source sourcetype
```

---

### Search Head

**Role:** Search interface in **Search & Reporting**; uses **SPL**.

**Example SPL**

```spl
index=VPN_Logs user=Maleena
```

**Explanation:**
Searches logs for a specific user.

**Concrete example**

```spl
index=VPN_Logs user=Maleena | stats count
```

## 4) Key SPL Quick Reference

### Count all events

```spl
index=VPN_Logs | stats count
```

**Example result:** `2862`

---

### Count events for one user

```spl
index=VPN_Logs user=Maleena | stats count
```

**Example result:** `60`

---

### Find user by IP

```spl
index=VPN_Logs src_ip="107.14.182.38" | stats values(user)
```

**Example result:** `Smith`

---

### Exclude a country

```spl
index=VPN_Logs NOT Country=France | stats count
```

**Example result:** `2814`

---

### Count events for one IP

```spl
index=VPN_Logs src_ip="107.3.206.58" | stats count
```

**Example result:** `14`

---

### Group by field

```spl
index=VPN_Logs | stats count by user
```

**Concrete example**

```spl
index=VPN_Logs | stats count by Country
```

---

### Show clean table

```spl
index=VPN_Logs | table _time user src_ip Country
```

---

## Gotchas

* **No data?** Check the correct index name (`VPN_Logs`).
* **Wrong field name?** Verify actual fields first with `table` or raw events.
* **No results?** Check capitalization and exact values (e.g. `Country=France`).
* **Upload confusion?** The lab uses **Upload** for local file import, but **Monitor** is the files/ports collection option in Add Data.
