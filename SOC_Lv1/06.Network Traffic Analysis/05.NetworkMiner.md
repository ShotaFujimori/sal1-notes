# 🔍 Network Traffic Analysis: NetworkMiner — Reference Sheet

> **TL;DR:** NetworkMiner is a Network Forensic Analysis Tool (NFAT) used to parse PCAP files and passively sniff traffic. Its primary strength is rapid host profiling — OS fingerprinting, credential extraction, file reassembly, and session mapping — making it ideal for initial triage before deep-diving with Wireshark or tcpdump.

---

## ⚠️ Gotchas

| Gotcha | Detail |
|---|---|
| Not a primary sniffer | NetworkMiner has sniffing capability, but it is NOT recommended as a primary sniffer. Use Wireshark/tcpdump instead. |
| Sniffer mode is Windows-only | The sniffing feature only works on Windows; all other features work on Windows, Linux, and macOS/FreeBSD. |
| OSINT lookup is premium-only | OSINT lookup for hosts and Alexa Top 1M in the DNS tab require the paid Professional edition. |
| Keyword search needs a reload | After adding/changing keywords in the Keywords tab, you **must** click "Reload Case Files" — results won't update automatically. |
| Frame processing removed in v2 | The Frames tab (showing per-frame detail) only exists in v1.6; it was removed in v2.x. |
| Packet detail view is v1.6 only | Granular sent/received packet details are available in v1.6 but not in v2.x. |
| MAC conflict detection is v2+ only | Duplicate MAC address detection (ARP spoofing indicator) is only available in v2.x and above. |
| Parameter coverage differs by version | v2.x extracts significantly more parameters than v1.6; v1.6 misses many HTTP query string parameters. |
| Large PCAPs may be slow | Loading large PCAP files can take up to a minute; missing frames may require reloading the PCAP. |
| Cleartext tab removed in v2 | The Cleartext tab (all cleartext data in one view) exists in v1.6 only; v2 moved this into the Keywords tab. |
| Not an IDS | NetworkMiner is not an IDS — it has limited anomaly detection (EternalBlue, ARP spoofing) but should not replace dedicated IDS tools. |
| NTLM hashes need external cracking | Extracted NTLM/Kerberos hashes must be cracked with Hashcat or John the Ripper — NetworkMiner doesn't crack them itself. |

## 🧰 What is NetworkMiner?

| Capability | Description |
|---|---|
| Traffic Sniffing | Intercepts and logs packets on the network (Windows only; not recommended as primary sniffer) |
| PCAP Parsing | Parses .pcap files and displays packet content in detail |
| Protocol Analysis | Identifies protocols used in captured traffic |
| OS Fingerprinting | Detects host OS from PCAP using Satori and p0f |
| File Extraction | Extracts images, HTML files, and emails from PCAP |
| Credential Grabbing | Extracts credentials and password hashes from PCAP |
| Cleartext Keyword Parsing | Extracts cleartext strings and keywords from PCAP |

---

## 🖥️ Operating Modes

| Mode | Description | Recommended? |
|---|---|---|
| Sniffer Mode | Live packet capture from network interface | ❌ Not recommended; Windows-only, less reliable |
| Packet Parsing / Processing | Load and analyse existing PCAP files | ✅ Primary use case; cross-platform |

## 🆚 NetworkMiner vs. Wireshark

| Feature | NetworkMiner | Wireshark |
|---|---|---|
| Purpose | Quick overview, data extraction, host mapping | In-depth packet analysis |
| GUI | ✅ | ✅ |
| Sniffing | ✅ (limited) | ✅ |
| Handling PCAPs | ✅ | ✅ |
| OS Fingerprinting | ✅ | ❌ |
| Parameter/Keyword Discovery | ✅ | Manual |
| Credential Discovery | ✅ | ✅ |
| File Extraction | ✅ | ✅ |
| Filtering Options | Limited | ✅ Full |
| Packet Decoding | Limited | ✅ Full |
| Protocol Analysis | ❌ | ✅ |
| Payload Analysis | ❌ | ✅ |
| Statistical Analysis | ❌ | ✅ |
| Host Categorisation | ✅ | ❌ |
| Cross-Platform | ✅ | ✅ |

> **Best Practice:** Capture → Quick overview in NetworkMiner (low-hanging fruit) → Deep investigation in Wireshark.

## 📂 UI Overview — Tabs & Panels

### Main Menu

| Menu | Function |
|---|---|
| File | Load PCAP (`Ctrl+O`), Receive PCAP over IP (`Ctrl+R`), Exit |
| Tools | Clear GUI (`Ctrl+N`), Delete Captured Data (`Ctrl+Delete`) |
| Help | Check for Updates, About NetworkMiner |

### Case Panel (top right)
- Lists all loaded PCAP files with filename and MD5 hash
- Right-click → Show Metadata: Start/End time, frame count, MD5, parsing time, endianness, data link type
- Can reload, remove, or view parent folder of loaded files

## 🗂️ Tab Reference

### Hosts Tab

| Field | Description |
|---|---|
| IP Address | Identified IP of the host |
| MAC Address | Hardware address (v2+ can detect duplicate MACs) |
| OS Type | Fingerprinted OS via Satori / p0f |
| Open Ports | Detected open TCP/UDP ports |
| Sent / Received Packets | Traffic volume per host |
| Incoming / Outgoing Sessions | Session count and details |
| Host Details | Web server banner, etc. |

- Sort options: IP (asc/desc), MAC, Hostname, Sent/Received Packets/Bytes, Open TCP Ports
- Right-click: Copy Text, Set Host Color, OSINT lookup (premium only)

---

### Sessions Tab

| Field | Description |
|---|---|
| Frame Number | Frame where the session was detected |
| Client / Server Address | Endpoints of the session |
| Source / Destination Port | Port numbers |
| Protocol | Application layer protocol |
| Start Time | When the session began |

**Filter Input Types:**
| Type | Example |
|---|---|
| `ExactPhrase` | Match complete phrase |
| `AllWords` | All listed words must appear |
| `AnyWord` | At least one word must appear |
| `RegExe` | Regular expression pattern |

---

### DNS Tab

| Field | Description |
|---|---|
| Frame Number | Frame number of DNS query |
| Timestamp | Time of the query |
| Client / Server | DNS client and resolver |
| Source / Destination Port | Usually UDP 53 |
| IP TTL | Time-to-live of the IP packet |
| DNS Time | Query response time |
| Transaction ID / Type | DNS transaction details |
| DNS Query / Answer | Queried hostname and resolved IP |
| Alexa Top 1M | Domain ranking (premium only) |

---

### Credentials Tab

| Type | Description |
|---|---|
| Kerberos Hashes | Extracted from Kerberos authentication |
| NTLM Hashes | Extracted from NTLM challenge-response |
| RDP Cookies | Remote Desktop Protocol cookies |
| HTTP Cookies | Session cookies from web traffic |
| HTTP Requests | Request headers containing auth |
| IMAP | Email client credentials |
| FTP | FTP username/password (cleartext) |
| SMTP | Mail sender credentials |
| MS SQL | Database login credentials |

- Checkbox: "Show Cookies" / "Mask NTLM challenge-response"
- Right-click: Copy Username, Copy Password, Auto-resize columns
- Cracking tools: **Hashcat**, **John the Ripper**

---

### Files Tab

| Field | Description |
|---|---|
| Frame Number | Frame where file transfer was detected |
| Filename / Extension | Reconstructed filename |
| Size | File size |
| Source / Destination Address | Transfer endpoints |
| Source / Destination Port | Port used |
| Protocol | e.g. HTTP, FTP |
| Timestamp | Transfer time |
| Reconstructed Path | Local path where file is saved |
| Details | Additional metadata |

- Right-click: Open File, Open Folder, Copy path, File Details, OSINT hash lookup (premium)

---

### Images Tab
- Shows extracted images from PCAP
- Hover over image → shows source/destination address and file path
- Right-click: Open Image, Zoom In (`Ctrl++`), Zoom Out (`Ctrl+-`)

---

### Parameters Tab

| Field | Description |
|---|---|
| Parameter Name | HTTP header name, query string key, etc. |
| Parameter Value | Corresponding value |
| Frame Number | Source frame |
| Source / Destination Host | Endpoints |
| Source / Destination Port | Port numbers |
| Timestamp | Time of capture |
| Details | Type (HTTP Header, HTTP QueryString, etc.) |

- Right-click: Copy Parameter Name, Copy Parameter Value, Auto-resize columns

---

### Keywords Tab

| Field | Description |
|---|---|
| Frame Number | Frame containing the keyword |
| Timestamp | Time of frame |
| Keyword | Matched keyword string |
| Context | Surrounding text context |
| Source / Destination Host | Endpoints |
| Source / Destination Port | Ports |

**Workflow:**
1. Enter keyword(s) in the input box
2. Click **Add** (or load from text file)
3. Click **Reload Case Files** — required for results to appear
4. Multiple keywords supported; each requires a reload after adding

---

### Messages Tab

| Field | Description |
|---|---|
| Frame Number | Source frame |
| Source / Destination Host | Sender/receiver hosts |
| Protocol | e.g. IMAP, SMTP |
| Sender (From) | Email/chat sender |
| Receiver (To) | Email/chat recipient |
| Timestamp | Message time |
| Size | Message size |

- Select a message to view attributes and attachments
- Right-click: Open File, Open Folder (for attachments)

---

### Anomalies Tab
- Flags detected anomalies in PCAP
- Detection types:
  - ARP spoofing (MAC address change / conflict)
  - **EternalBlue** exploit attempts (based on frame size heuristics)
- Not a full IDS — limited detection scope

## 🔄 Version Comparison: v1.6 vs v2.7

| Feature | v1.6 | v2.7 |
|---|---|---|
| MAC Address Conflict Detection | ❌ | ✅ |
| Frame Processing Tab | ✅ | ❌ |
| Per-Packet Detail View | ✅ (granular) | ❌ (removed) |
| Cleartext Tab | ✅ | ❌ |
| Parameter Extraction | Limited | ✅ More extensive |
| EternalBlue Detection | ✅ | ✅ |

> **Rule of thumb:** Use v1.6 when you need granular frame/packet detail. Use v2.7 for MAC conflict detection and richer parameter extraction.
